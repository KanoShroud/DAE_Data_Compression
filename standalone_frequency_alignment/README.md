# 插值频谱补全与双站 TDOA 对齐：独立验证路线

本目录不接入 `main.py`，也不修改 V5-A.1、Shared64 或现有训练/评估代码。它只回答一个问题：A、B 两站可用频点不同后，把稀疏频谱做 IFFT、整数倍插值、滤波、再 FFT，是否真的能补出缺失频点并改善 TDOA。

## 实现口径

- 双站独立 Zhai 扩展：A、B 分别用自己的本地周期图 `|X[k]|²` 运行 Zhai 的0–1逐点交换选频，因此两站掩码可以不同；该扩展仅由 `local_zhai_smoke` 验证，不是 BPSK 参数扫描的主掩码机制。
- BPSK 正式主实验：A、B 的集合由目标重叠率联合随机构造，严格控制各站保留数和真实交集数，从而将“共同频点数量”的影响与某次含噪周期图和 Zhai 搜索迭代分开。
- 原论文非对称对照：B 本地选频，中心站 A 保留全频并匹配 B 的频点。B 只需上报所选复频点和索引，A 不需要先向 B 发送频谱。
- Zhai 目标：令 `ωk=2πfk`，以本地周期图作为功率的插件估计，最大化选中频点功率加权角频率方差 `J=S2-S1²/S0`；在固定噪声尺度与增益归一化下，这等价于最小化时延 CRLB 的共同因子。它用于相对选频，不作为受控主实验的绝对 CRLB 数值报告。
- 插值方法：理想周期插值、多相 FIR、周期线性和周期三次样条。上采样后的滤波严格称为抗镜像滤波，不称为抗混叠滤波。
- 插值得到的值不作为新独立观测，不加入 CRLB 信息求和。

## 最重要的数值一致性检验

两站原本就处在相同的 N 点 DFT 频率网格上，只是频点集合不同。对稀疏频谱做任意周期线性时不变插值，再映射回原始 DFT 网格，未观测频点仍为零。理想周期插值必须与零填充等价，插值算子秩不得超过实际观测数 M。入口脚本会先自动验证这些条件；失败就停止，不输出性能结论。

## 运行方法

在 PyCharm 打开 `run_interpolation_alignment.py`，修改顶部普通变量：

```python
PROFILE = "sanity"
```

可选配置：

- `sanity`：数值一致性检验和极小流程检查；
- `smoke`：小样本、受控重叠比例的完整输出检查；
- `local_zhai_smoke`：A、B 分别运行严格 Zhai 选频；
- `synthetic_full`：论文式合成 Monte Carlo，耗时较长；
- `project_smoke`：调用现有 `SignalSimulator` 的 urban8/LOS 小样本检查；
- `project_full`：项目场景完整验证，必须由用户在 PyCharm 中运行。

结果保存到 `运行结果/频谱插值对齐/YYYYMMDD_HHMMSS/`，包含配置、协议清单、逐试验 CSV、汇总 CSV、配对比较、算子诊断、绘图数据和 SVG。

## 导师汇报绘图

`plot_interpolation_mechanism.py` 独立读取既有 `synthetic_full` 正式结果，不重新运行 Monte Carlo 实验。脚本生成三组图：

- 插值前后的时域波形、原始 DFT 频谱和缺失频点能量；
- 真实交集、原网格确定性补全、完整频谱和联合集合真实频谱对照的连续时延匹配得分；
- 重叠率、SNR、离群率和配对置信区间组成的 TDOA 性能图。

波形和频谱图使用四个固定子种子分别展示平滑复谱、平滑幅度随机相位谱、宽带随机复谱和多频带随机相位谱；时延得分图完整列出九种对照方法，并对完全重合的五种原网格确定性补全作显式说明。这些机制样本只用于解释插值过程，统计性能图严格来自既有逐试验结果。直接在 PyCharm 运行该脚本即可，默认读取
`运行结果/频谱插值对齐/20260714_184753_411401_synthetic_full`。输出同时保存到正式结果的 `figures/advisor_report/` 和 Obsidian 汇报图片目录。使用 `--validate-only` 可只检查数据与数值一致性检验而不生成图片。

## BPSK 扩展参数扫描

`run_bpsk_parameter_sweep.py` 是与旧 `synthetic_full` 完全分离的新入口。它不会改写旧配置、旧 trial 或旧图片，并在新结果目录中保存旧正式结果关键文件的 SHA-256。冻结参数为：

- DFT 长度 `N=512`；
- 单站频点数 `M=256/128/64/32`；
- SNR=`-5/0/5/10/15 dB`；
- 重叠率=`0/0.25/0.5/0.75/1`；
- 四类既有机制频谱加 Urban8 同参数 BPSK-RRC；
- 每条件300次，共500个条件、150,000个基础试验和1,500,000条方法结果；
- 真实时延与搜索范围均为 `[-25,25] sample`，网格步长0.01 sample。

BPSK-RRC 使用与 `signal_gen.py` 相同的 BPSK、每符号2点、RRC滚降0.2和8符号跨度，但不引入 Urban8 几何或多径。这样只检验目标波形结构是否改变插值结论。

正式运行按条件写入 `condition_chunks/*.csv.gz`，支持 `--resume <结果目录>` 断点续跑。运行脚本先对四种 `M` 和五种原网格确定性补全执行数值一致性检验；检验通过后，正式 Monte Carlo 复用交集的同一次 TDOA 估计并分别保存完整方法行。绘图脚本另行精确重放500个正式条件的首个试验，真正执行五种频谱重构、按相对观测幅度阈值统计插值输出的有效共同频点，并独立复算400个可估计试验的 TDOA，用于避免把复用结果自身作为等价性证明。

新增“时域补零密集频谱”（Time-Zero-Padded Dense Spectrum，代码字段 `TZP-DS`）对照。它把每站稀疏频谱 IFFT 为512点复数 IQ 序列，在末尾补零至4096点，再 FFT 得到8倍密集频率栅格，并直接在密集互谱上进行0.01 sample连续时延搜索。该方法保持每站实际传输 `M` 个复频点，不复用交集估计。正式运行前还检查：原频点一致性、原未选频点仍为零、算子秩等于 `M`，以及 ZoomFFT 与定义式直接求和一致。

`plot_bpsk_parameter_sweep.py` 读取完成后的500个 trial chunk，导出：

- 五类信号的含噪频谱、复数 IQ 波形、映射频谱和缺失频点图，时域插值处理 I/Q 而不是 `abs(IQ)`；
- 原网格确定性补全等价性、缺失能量和由插值输出实测的有效共同频点率图；
- 5类信号 × 4种 `M` 的50%重叠 TDOA MAE 与 RMSE 性能网格；
- 真实交集 MAE/RMSE 热图和重叠率曲线，热图采用“数值越大颜色越深”的反向顺序色图；
- 非对称选频、真实交集和联合集合真实频谱对照的分 SNR MAE/RMSE 对照图；
- 时域补零后的密集频谱、相关得分、分 SNR 误差、有限输出率、数值非零率和稳健性/实现审计，共11张正式报告图；
- `report_tables/` 下的总体、分信号、分频点预算、BPSK、配对、算子、边界敏感性、条件效应和估计器重放数据表；
- SVG 与300 dpi PNG，以及 Obsidian assets 副本。

全部子图采用“编号. 标题”的下置子图标题。MAE 与 RMSE 分图展示：MAE 反映平均绝对误差，RMSE 对少量远端错峰更敏感；RMSE 性能网格的误差棒使用每条件2,000次固定种子非参数 bootstrap 95%区间。报告正文统一将方案名写为“非对称选频”，`Zhai-Asymmetric` 仅保留为结果文件中的兼容代码字段。

本轮正式结果位于 `运行结果/频谱插值对齐/20260721_172703_080303_bpsk_parameter_sweep`。150,000个基础试验和1,500,000条方法结果全部完成。120,000个正重叠配对试验中，五种原网格确定性补全相对真实交集的点估计、绝对误差、平均改善和95%区间均严格为零；时域补零密集频谱相对真实交集的平均 MAE 改善为 `-0.2915 sample`，重新抽样95%区间为 `[-0.3178,-0.2671]`。正重叠条件下，真实交集与时域补零密集频谱的 MAE/RMSE 分别为 `2.6089/7.9421` 与 `2.9004/8.3158 sample`。按400个正式条件等权时，TZP-DS 在316个条件更差、84个条件更好，故结论是“当前固定设置下整体无增益且存在损失”，而非所有条件都必然恶化。去除搜索边界附近试验后，平均 MAE 改善仍为 `-0.2674 sample`。零重叠时，密集互谱仍能输出数值，但 MAE/RMSE 达 `17.5453/22.9652 sample`，说明数值非零点不能替代真实共同观测。

## 结论判定规则

只有插值方法在相同连续时延估计器下稳定优于 `Intersection-Continuous`，且配对置信区间不跨零，才可称为 TDOA 性能改善。若只优于整数采样点搜索，只能称为搜索网格加密；若缺失频谱 NMSE 和相位没有改善，只能称为平滑或滤波效应，不能称为真实频谱恢复。
