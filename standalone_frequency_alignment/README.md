# 插值频谱补全与双站 TDOA 对齐：独立验证路线

本目录不接入 `main.py`，也不修改 V5-A.1、Shared64 或现有训练/评估代码。它只回答一个问题：A、B 两站各自选择不同频点后，把稀疏频谱做 IFFT、整数倍插值、滤波、再 FFT，是否真的能补出缺失频点并改善 TDOA。

## 实现口径

- 双站独立扩展：A、B 分别用自己的本地周期图 `|X[k]|²` 运行 Zhai 学位论文中的严格 0-1 逐点交换选频，因此两站掩码可以不同。
- 原论文非对称对照：B 本地选频，中心站 A 保留全频并匹配 B 的频点。B 只需上报所选复频点和索引，A 不需要先向 B 发送频谱。
- Zhai 目标：令 `ωk=2πfk`，最大化选中频点功率加权角频率方差 `J=S2-S1²/S0`；对应 `CRLB=0.5(σA²+σB²/|α|²)/J`。统一缩放全部频率不会改变最终选频集合，但会改变 CRLB 的数值单位。
- 插值方法：理想周期插值、多相 FIR、周期线性和周期三次样条。上采样后的滤波严格称为抗镜像滤波，不称为抗混叠滤波。
- 插值得到的值不作为新独立观测，不加入 CRLB 信息求和。

## 最重要的理论门禁

两站原本就处在相同的 N 点 DFT 频率网格上，只是频点集合不同。对稀疏频谱做任意周期线性时不变插值，再映射回原始 DFT 网格，未观测频点仍为零。理想周期插值必须与零填充等价，插值算子秩不得超过实际观测数 M。入口脚本会先自动验证这些条件；失败就停止，不输出性能结论。

## 运行方法

在 PyCharm 打开 `run_interpolation_alignment.py`，修改顶部普通变量：

```python
PROFILE = "sanity"
```

可选配置：

- `sanity`：理论门禁和极小流程检查；
- `smoke`：小样本、受控重叠比例的完整输出检查；
- `local_zhai_smoke`：A、B 分别运行严格 Zhai 选频；
- `synthetic_full`：论文式合成 Monte Carlo，耗时较长；
- `project_smoke`：调用现有 `SignalSimulator` 的 urban8/LOS 小样本检查；
- `project_full`：项目场景完整验证，必须由用户在 PyCharm 中运行。

结果保存到 `运行结果/频谱插值对齐/YYYYMMDD_HHMMSS/`，包含配置、协议清单、逐试验 CSV、汇总 CSV、配对比较、算子诊断、绘图数据和 SVG。

## 结论判定规则

只有插值方法在相同连续时延估计器下稳定优于 `Intersection-Continuous`，且配对置信区间不跨零，才可称为 TDOA 性能改善。若只优于整数采样点搜索，只能称为搜索网格加密；若缺失频谱 NMSE 和相位没有改善，只能称为平滑或滤波效应，不能称为真实频谱恢复。
