# 第一部分：文献综述

## 1.1 面向估计的数据压缩理论基础

### 1.1.1 MSE 失真的局限性

<a href="#ref-1">[1] Fowler</a> 首次系统论证了 MSE 失真准则在 TDOA/FDOA 定位中的两大缺陷（全文提取）：
1. **MSE 增加可能不影响参数精度**——如只改变相位不改变幅度，压缩可能看起来增大了 MSE 但实际没有损害参数估计
2. **参数精度还取决于信号的频谱结构因素**——TDOA 精度依赖于信号的 RMS 带宽，FDOA 精度依赖于 RMS 持续时间，这些因素是 MSE 完全无法捕捉的

<a href="#ref-1">[1] Fowler</a> 最终提出了一个能**捕捉压缩对参数精度真实影响**的新失真度量，并通过简单示例验证了其相对于 MSE 度量的优越性——这是面向定位任务的任务导向压缩思想的最早系统阐述

**补充证据**（<a href="#ref-2">[2] Fowler</a>, "Decimation vs. quantization for data compression in TDOA systems"）：
- 抽取和量化的组合可以满足单独量化无法满足的数据传输时间要求
- 当量化方法能满足要求时，抽取/量化组合可以获得更好的 TDOA 精度
- 关键洞察：TDOA 精度取决于信号的 RMS 带宽，因此可以显著减少数据量而不影响 RMS 带宽的压缩技术有很大潜力

**<a href="#ref-3">[3] Fowler</a> 系统化权衡分析**（新增补充）：
<a href="#ref-3">[3] Fowler</a> 在 AFRL 技术报告中系统建立了 TDOA/FDOA 定位中的多维权衡框架：

- **四个研究方向**：
  1. 新理论结果——扩展了如何用数据压缩实现定位处理序列中各任务之间的权衡
  2. 改进与扩展——将短时傅里叶变换（STFT）整合到数据压缩算法中并验证
  3. MATLAB 测试平台——开发并集成了数据压缩例程
  4. 通用定位研究——发现声纳模型下的结果直接用于通信信号存在危险性

- **关键发现**：数据压缩可以赋能不同定位任务之间的权衡，压缩方案应根据具体信号模型设计，不能简单跨域迁移

**对当前项目的启示**：
- DAE 用 MSE 训练，可能保留了对信号重建重要但对 TDOA 不重要的信息
- 应考虑使用面向 TDOA 的失真准则（如 Fisher 信息）
- 可以借鉴抽取/量化组合思想，在 DAE 中引入频带选择性

**关键论文**:
 - <a href="#ref-1">[1]</a> M. Fowler, "New distortion measures for data compression for emitter location," in *Proc. 2001 Asilomar Conf.*, vol. 1, pp. 658-662. ✅ 有PDF
 - <a href="#ref-2">[2]</a> M. Fowler, "Decimation vs. quantization for data compression in TDOA systems," in *Proc. SPIE*, vol. 4122, pp. 56-67, 2000. ✅ 有PDF
 - <a href="#ref-3">[3]</a> M. Fowler, "Data compression trade-offs for TDOA/FDOA geo-location systems," AFRL-RI-RS-TR-2008-31, Final Technical Report, Feb. 2008. ✅ 有PDF

### 1.1.2 Fisher 信息失真准则

Fowler 和 Chen <a href="#ref-4">[4]</a> 提出了基于 Fisher 信息的数据压缩方法：

**技术原理**（全文提取）：
- Fisher 信息矩阵量化了观测数据对参数估计的信息量
- 压缩后保留 Fisher 信息最大的数据分量
- 通过**操作率失真（Operational Rate-Distortion）**框架优化比特分配
- 使用 **Lagrange 乘子法的整数优化版本**高效确定最优操作点——这是从连续优化到离散比特分配的关键步骤
- 给出了使用变换后数据显式计算 Fisher 信息的操作度量方法

**关键结果**：
- Fisher 信息方法在 TDOA 和 FDOA 估计中**均显著优于 MSE 方法**
- 特别关注了两个传感器都无法单独估计参数的场景——这直接对应分布式 UAV 场景中单个 UAV 数据不足以定位的情形
- 变换编码可以有效捕捉压缩对估计精度的影响
- 支持在操作率失真框架内高效优化

**Fowler & Chen 2006** <a href="#ref-5">[5]</a>：从数据中直接评估 Fisher 信息：

Fowler 和 Chen <a href="#ref-5">[5]</a> 进一步提出了从数据本身而非模型推导来评估 Fisher 信息的方法——这对工程实现至关重要：

**核心问题**：传感器网络中，需要根据传感器数据质量决定如何使用该传感器的数据，而 Fisher 信息是评估数据质量的天然方式。但直接从采集数据中数值计算 Fisher 信息存在困难。

**关键发现**（全文提取）：
- **正交滤波器组**：适合压缩任务（去相关、临界采样），但**不适合** Fisher 信息（FI）评估——时域混叠破坏了频率分辨率，无法分辨哪些频段携带最多的 TDOA 信息
- **短时傅里叶变换（STFT）**：适合 FI 评估（清晰的时频分辨率，每个时频点的 Fisher 信息可单独计算），但**不适合**压缩（冗余表示，数据量大）
- **混合架构解决方案**：STFT 用于时频域 FI 评估 → 确定各频段对 TDOA 的信息贡献 → 正交滤波器组执行实际压缩——两者各司其职
- 这是**首次从工程实现角度**解决 FI 驱动数据压缩的可行性问题

**对当前项目的启示**：
- DAE 编码器类似于正交滤波器组——压缩效率高，但其内部表示难以直接用于 Fisher 信息评估
- 可以考虑类似混合架构：使用 STFT 或其他频谱分析工具评估各频段对 TDOA 的信息贡献，再将评估结果用于指导 DAE 训练或压缩率分配
- 直接对应创新方案7（频带选择性压缩）（→见 [§2.5](#25-p1频带选择性压缩方案7)）的技术实现路径

**关键论文**:
 - <a href="#ref-4">[4]</a> M. Fowler and D. Chen, "Fisher-information-based data compression for estimation using two sensors," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 41, no. 3, pp. 1131-1137, Jul. 2005. ✅ 有PDF
 - <a href="#ref-5">[5]</a> M. Fowler and M. Chen, "Evaluating fisher information from data for task-driven data compression," in *Proc. ICASSP 2006*, vol. 4, pp. IV-967–IV-970, 2006. ✅ 有PDF
 - <a href="#ref-22">[22]</a> A. Baroughi and A. Shirazi, "Fisher information based signal compression in TDOA estimation application," in *Proc. 2009 CSI Comput. Conf.*, pp. 299-304. ✅ 有PDF

### 1.1.3 率失真理论的次优性

<a href="#ref-10">[10] Weiss</a> 推导了分布式定位中率失真最优压缩的精度极限：

**核心发现**：
- 传统率失真最优压缩（最小化 MSE）在定位任务中是次优的
- MSE 失真准则可能消除定位信息（如信号的高频分量）
- 简单的频带选择性压缩方案可以大幅优于率失真压缩

**数学框架**：
- 使用高斯率失真测试信道模型
- 结合 Whittle 谱 Fisher 信息表征
- 获得显式的频域 Cramér-Rao 下界

**关键定理**（从全文提取）：
- 率失真最优压缩在 MSE 准则下，会优先保留信号能量最大的频段
- 但定位信息可能集中在能量较低的频段（如高频分量提供时间分辨率）
- 因此 RD-optimal 压缩可能消除定位信息，导致定位精度下降数个数量级

**关键结果**：
- 两频带、两电平特化给出闭式表达
- 两频带闭式解揭示了**速率诱导的机制转换（rate-induced regime change）**：压缩率超过临界值后，RD-最优压缩系统性丢弃高频段，定位精度发生相变式崩溃
- 简单的频带选择性方案在相同比率下可优于 RD 压缩数个数量级

**关键论文**:
 - <a href="#ref-10">[10]</a> A. Weiss, "On the suboptimality of rate-distortion-optimal compression: fundamental accuracy limits for distributed localization," *IEEE Signal Process. Lett.*, vol. 33, pp. 1566-1570, 2026. ✅ 有PDF

### 1.1.4 量化数据的参数估计理论

量化压缩方法在信号处理和定位领域有深厚的理论基础，以下为经典理论工作：

**经典理论基础**：
- **Van Vleck & Middleton (1966)** <a href="#ref-68">[68]</a>，"The spectrum of clipped noise"：推导了硬限幅自相关函数的 arcsin 律——输入高斯信号经硬限幅后，自相关函数 ρ_clip = (2/π)·arcsin(ρ_original)，从 1-bit 数据中恢复相关结构的理论基础
- **Stoica et al. (2022)** <a href="#ref-69">[69]</a>，"The Cramér–Rao bound for signal parameter estimation from quantized data"：系统推导了量化数据参数估计的 CRB（针对毫米波雷达等超宽带应用），为量化方案设计提供了理论基准
- **Dabeer & Karnik (2006)** <a href="#ref-70">[70]</a>，"Signal parameter estimation using 1-bit dithered quantization"：提出了**不需要已知抖动信号和噪声分布**的一致估计量——在实际系统中噪声分布往往未知，这一特性使抖动量化具有工程实用性
- **Xiao et al. (2023)** <a href="#ref-72">[72]</a>，"Covariance matrix recovery from one-bit data with non-zero quantization thresholds"：非零阈值克服传统零阈值 arcsin 律无法恢复协方差对角元素的局限
- **Fang et al. (2025)** <a href="#ref-73">[73]</a>，"Mixed-precision quantization"：提出从搜索角度解决混合精度量化中的比特分配问题——不同传感器/任务分配不同量化比特数，性能优于固定精度量化

**对当前项目的启示**：
- DAE 压缩本质上也是一种"量化"（将高维信号映射到低维潜空间），量化理论为理解 DAE 压缩的信息损失提供了分析工具
- arcsin 律提示：即使经过极端非线性变换（如 1-bit 硬限幅），GCC 结构的信息仍然保留

**关键论文**:
 - <a href="#ref-68">[68]</a> J. Van Vleck and D. Middleton, "The spectrum of clipped noise," *Proc. IEEE*, vol. 54, no. 1, pp. 2-19, 1966.
 - <a href="#ref-69">[69]</a> P. Stoica et al., "The Cramer-Rao bound for signal parameter estimation from quantized data," *IEEE Signal Process. Mag.*, vol. 39, no. 1, pp. 118-125, 2022.
 - <a href="#ref-70">[70]</a> O. Dabeer and A. Karnik, "Signal parameter estimation using 1-bit dithered quantization," *IEEE Trans. Inf. Theory*, vol. 52, no. 12, pp. 5389-5405, 2006.
 - <a href="#ref-72">[72]</a> Xiao et al., "Covariance matrix recovery from one-bit data with non-zero quantization thresholds," *IEEE Trans. Signal Process.*, 2023.
 - <a href="#ref-73">[73]</a> Fang et al., "Mixed-precision quantization: make the best use of bits where they matter most," *IEEE Trans. Signal Process.*, 2025.

## 1.2 经典压缩-估计方法

### 1.2.1 变换编码方法

**基于 SVD 的压缩**（<a href="#ref-16">[16] Pourhomayoun</a>，全文提取）：
- 利用雷达脉冲序列的脉冲间冗余进行 SVD 分解
- 提取主要奇异向量实现数据压缩
- **关键发现**：SVD 压缩不仅降低数据传输量，还具有**去噪效应**——在较小压缩比下，SVD 压缩后的定位精度**反而优于无压缩的情况**，因为 SVD 过程同时滤除了噪声分量
- 这一"压缩同时去噪"的效应与 DAE 的机理高度相似——DAE 的潜空间压缩也在同时进行去噪和降维

**基于 SVD + Fisher 信息的联合方法**（<a href="#ref-8">[8] Fowler</a>）：
- 综合利用 SVD 的降维能力和 Fisher 信息的面向估计特性
- 在雷达辐射源定位场景中验证
- 证明 SVD+Fisher 信息方法优于纯 SVD 或纯 Fisher 信息方法

**非 MSE 小波压缩**（<a href="#ref-7">[7] Fowler</a>）：
- 使用小波包变换进行信号分解
- 基于非 MSE 失真准则（考虑 RMS 带宽）选择小波系数
- 实现面向 TDOA 的专用压缩

**频域抽取压缩**（<a href="#ref-35">[35] Zhai</a>）：
- 基于凸优化的抽取压缩采样技术
- 对于频域稀疏信号，显著降低 RMSE 性能损失
- 相比传统幅度谱排序方法有明显改进

**关键论文**:
 - <a href="#ref-16">[16]</a> M. Pourhomayoun and M. Fowler, "An SVD approach for data compression in emitter location systems," in *Proc. 2011 Asilomar Conf.*, pp. 257-261. ✅ 有PDF
 - <a href="#ref-8">[8]</a> M. Fowler et al., "Data compression using SVD and fisher information for radar emitter location," *Signal Process.*, vol. 90, no. 7, pp. 2190-2202, Jul. 2010. ✅ 有PDF
 - <a href="#ref-7">[7]</a> M. Fowler, "Non-MSE wavelet-based data compression for emitter location," in *Proc. SPIE*, vol. 4475, pp. 13-22, 2001. ✅ 有PDF
 - <a href="#ref-35">[35]</a> J. Zhai et al., "TDOA estimation method based on frequency domain decimation," in *Proc. ICSPS 2024*, vol. 13559, pp. 313-322. ✅ 有PDF

### 1.2.2 量化与抽取方法

**粗量化**（<a href="#ref-6">[6] Fowler</a>）：
- 分析了两种块自适应量化方案（R/I 和 M/P）
- 推导了量化后 SNR 和相关后 SNR 的关系
- 提出了 M/P 方案的最优比特分配规则

**Baroughi 2009 DFT 相位压缩** <a href="#ref-22">[22]</a>：提出了基于 Fisher 信息的计算高效比特分配方法（替代 Lagrange 乘子法的低复杂度方案），关键创新是**仅发送 DFT 系数的相位**而非实部+虚部——在保持 TDOA 精度的同时额外实现约 50% 的数据压缩

**抽取与量化的权衡**（<a href="#ref-2">[2] Fowler</a>，全文提取）：
- TDOA 精度取决于信号的 RMS 带宽——抽取降低 RMS 带宽但减少数据量，量化不改变 RMS 带宽但引入噪声
- **核心贡献**：推导了确定最优抽取-量化平衡的**定量判据**，证明抽取/量化组合可以满足单独量化无法满足的数据传输时限要求
- 这一判据可以直接用于指导 DAE 中压缩率（CR）和编码器结构的联合设计

**过采样低复杂度 1-bit A/D**（<a href="#ref-36">[36] Stein</a>）：
- 1-bit 量化引入非线性效应，在低 SNR 下性能损失显著
- 通过适度提高采样率可以补偿量化损失
- 使用 Fisher 信息矩阵下界近似粗量化接收机的估计性能

**关键论文**:
 - <a href="#ref-6">[6]</a> M. Fowler, "Coarse quantization for data compression in coherent location systems," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 36, no. 4, pp. 1269-1278, Oct. 2000. ✅ 有PDF
 - <a href="#ref-36">[36]</a> S. Stein, "Performance analysis for time-of-arrival estimation with oversampled low-complexity 1-bit a/d conversion," in *Proc. ICASSP 2017*, pp. 4491-4495. ✅ 有PDF

### 1.2.3 几何自适应压缩

Chen 和 Fowler <a href="#ref-18">[18]</a> 提出了几何自适应数据压缩方法：

**技术原理**（从全文提取）：
- 多传感器系统通常需要从数据中做出多个估计
- 这些多个估计通常有冲突的压缩需求
- 使用基于 Fisher 信息矩阵迹的失真度量
- 使用数值优化方法实现多个估计之间的压缩权衡

**多参数估计压缩**（<a href="#ref-19">[19] Chen, D.</a>）：
- TDOA 估计和 FDOA 估计对压缩有不同的需求
- 存在 TDOA 精度和 FDOA 精度之间的基本权衡
- 几何自适应压缩方案可以根据传感器-目标几何关系调整压缩策略

**对当前项目的启示**：
- 多个估计任务（如 TDOA + 定位）可能有冲突的压缩需求
- 可以借鉴几何自适应思想，根据信道条件调整压缩策略
- UAV 编队几何结构可能大幅影响最优压缩策略

**关键论文**:

### 1.2.4 交叉模糊函数压缩

- 可以考虑在 DAE 的潜空间中保留类似 CAF 的结构化表示

## 1.3 压缩感知方法

### 1.3.1 CS-TDOA 估计

**Wang 等人** 提出了基于不精确重构的 TDOA 估计方法（全文提取）：
- 在压缩感知框架下实现高精度 TDOA 估计（EIRCS 方法）
- 优化算法流程进一步降低计算复杂度
- **实验验证**（2025, *Scientific Reports*）：EIRCS 方法是**无偏估计**，在显著压缩采样数据的同时保持高精度 TDOA 估计
- 关键洞察：TDOA 估计不需要完美的信号重构——与 Weiss 的"MSE 不保留 TDOA 信息"理论一脉相承

**Jiao 等人** 提出了基于幅度相位聚类的压缩 TDOA 估计方法（全文提取）：
- 利用 PSK/QAM 信号的幅度相位特性，设计专用压缩矩阵
- 使用近似最大似然（AML）方法估计 TDOA
- **定量结果**：压缩采样下的 TDOA 估计精度在**全采样性能的一个数量级以内**
- 从会议版（2025 ICSPS）发展到期刊版（2026 IET Signal Process.），增加了时频域聚类，并将应用扩展到 OFDM-QAM 信号

**基于 Hadamard 矩阵的 CS-TDOA**（<a href="#ref-30">[30] Salari</a>，全文提取）：
- 利用 Hadamard 矩阵的特殊性质
- **核心创新**：消除了标准 CS 方法所需的复杂信号重构步骤——直接从 CS 测量中估计 TDOA，无需任何信号重建
- 这一"无重构"范式对 UAV 场景有重要启示：如果 TDOA 可以直接从压缩测量中获取，那么 DAE 解码器可能可以省略

**ML TDOA 从 CS 样本**（<a href="#ref-26">[26] Cao</a>）：
- CS 输出是时间样本的降维线性变换，打乱了时间关系
- 不能直接对 CS 输出做互相关来估计 TDOA
- 提出使用 CS 样本的 DFT 系数来估计 TDOA
- DFT 系数的相位与未知 TDOA 成正比
- ML 估计器性能最优但需要已知信号和噪声功率

**关键论文**:
 - <a href="#ref-31">[31]</a> Y. Wang et al., "The time difference of arrival estimation method utilizing an inexact reconstruction within the framework of compressed sensing," *Remote Sens.*, vol. 16, no. 21, Oct. 2024. ✅ 有PDF
 - <a href="#ref-32">[32]</a> Y. Wang et al., "Experimental analysis of time difference of arrival estimates based on inexactly reconstructed signals," *Sci. Rep.*, vol. 15, no. 1, p. 40862, Nov. 2025. ✅ 有PDF
 - <a href="#ref-33">[33]</a> X. Jiao et al., "Compressed sampling time difference of arrival estimation method based on amplitude and phase clustering," in *Proc. ICSPS 2024*, vol. 13559, pp. 288-295. ✅ 有PDF
 - <a href="#ref-34">[34]</a> X. Jiao et al., "Compressive TDOA estimation method based on amplitude phase clustering in time-frequency domain," *IET Signal Process.*, vol. 2026, no. 1, 2026. ✅ 有PDF
 - <a href="#ref-30">[30]</a> S. Salari et al., "TDOA estimation with compressive sensing measurements and hadamard matrix," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 54, no. 6, pp. 3137-3142, Dec. 2018. ✅ 有PDF
 - <a href="#ref-26">[26]</a> S. Cao et al., "Maximum likelihood TDOA estimation from compressed sensing samples without reconstruction," *IEEE Signal Process. Lett.*, vol. 24, no. 5, pp. 564-568, May 2017. ✅ 有PDF

### 1.3.2 CS-TDOA 的理论界

**Cramér-Rao 下界**（<a href="#ref-27">[27] Cao</a>）：
- 推导了 CS-TDOA 的 Cramér-Rao 下界
- 量化了 CS 带来的精度损失
- 提出了非相干处理方案减少采样通道数

**Ziv-Zakai 下界**（<a href="#ref-28">[28] Zhang, Y.</a>）：
- 使用 ZZB 方法开发贝叶斯 MSE 下界，分别推导确定性 ZZB 和随机性 ZZB 作为 CS 核的函数
- 对 CS 核和高斯噪声颜色没有限制；比贝叶斯 CRB 提供更好的性能预测，在全 SNR 范围内更紧致
- <a href="#ref-29">[29] Zhang, Y.</a> 将其扩展到零均值高斯信号的特化版本

**关键论文**:
 - <a href="#ref-27">[27]</a> S. Cao et al., "Compressive TDOA estimation: cramér-rao bound and incoherent processing," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 56, no. 4, pp. 3326-3331, Aug. 2020. ✅ 有PDF
 - <a href="#ref-28">[28]</a> Y. Zhang et al., "Ziv-Zakai bound for compressive time delay estimation," *IEEE Trans. Signal Process.*, vol. 70, pp. 4006-4019, 2022. ✅ 有PDF

### 1.4.1 深度学习方法深度阅读补充

以下为 complete 模式全文阅读的核心深度学习论文的关键定量发现：

**PNCC（<a href="#ref-50">[50] Dominguez</a>）**——最直接的竞争对手方法：
- TDOA MAE 降低 **49.4%**，多普勒 MAE 降低 **27.2%**，载波频率 MAE 降低 **76.3%**
- **SNR=-20 dB 仍能产生可见互相关峰**——证明优化互相关峰位置在极低 SNR 下极为有效
- PNCC 不需要真实互相关信号作为标签，只需真实 TDOA 峰位置——与方案0a（GCC峰值损失）设计理念一致

**<a href="#ref-51">[51] Xu</a>（多权重GCC+CNN+CSI联合回归）**——最相似的系统架构：
- 同时利用 I/Q 波形 + 多权重 GCC 特征图 + CSI，CNN 融合三种异构特征直接回归 TDOA
- 场测验证：TDOA 偏差相比 GCC-PHAT **降低 51%**，100 个场段平均定位误差 **19.67 km**
- 高 SNR 下已接近 CRLB——验证了深度学习 TDOA 估计的统计效率

**<a href="#ref-54">[54] Zhang, Z.</a>（GAN-CNN DOA估计）**——生成式增强范式：
- **-10 dB SNR** 下 DOA 精度 **72.2%**，仅 **50 快照**下保持 **93.8%** 精度
- GAN 中的**相位一致性损失函数**是关键创新——在抑制噪声的同时保持空间相位信息
- 与 DAE 的 GCC 相关性损失有异曲同工之妙

**<a href="#ref-58">[58] Dong</a>（深度张量补全DPD）**——结构化设计的必要性：
- DPD 似然张量 ≈ 秩一单峰张量 + 低秩背景张量
- **关键发现**：结构化方法可以将低重构误差成功转换为准确状态估计，而**通用 DNN 基线无法完成此任务**
- → 启示：面向定位的神经网络需要专门的结构化设计，不能直接套用通用架构

**<a href="#ref-45">[45] Li, Z.</a>（无网格1-bit ML-DPD）**——算法效率：
- 开发更精细的 MM 代理函数，得到**闭式最优解**，消除穷举搜索
- 消除网格量化误差（GQE）——在密集搜索网格场景下计算效率极高

**<a href="#ref-52">[52] Xia</a>（双分支CNN+迁移学习）**——实际部署的关键技术：
- 仿真定位精度 **14.37 km**，实际实验 **34.26 km**
- 迁移学习策略：大量仿真数据预训练 + 极少量实际数据微调
- → 对 UAV 场景训练数据稀缺问题有直接启示

**<a href="#ref-57">[57] Kirmaz</a>（ANN TDOA/TOA + 锚点选择）**——资源优化：
- <a href="#ref-56">[56] Kirmaz</a>：TDoA 估计在有限数据下比 ToA 精度高约 **20%**（但随着训练数据增加差距缩小）；<a href="#ref-57">[57] Kirmaz</a>：锚点选择策略可减少 **25%** 定位锚点同时保持或提升精度——直接验证了通信-计算联合优化的可行性
- → 为方案的通信-计算联合优化提供了数据支持

## 2.4 P0：GCC中心损失 → 理论版本（方案0b+0a，2026-06-24重构）

### 2.4.1 量纲分析发现

R13实验（CR自适应ε）失败后，实证测量揭示根因：

| 损失 | 实测值(随机初始) | 实测值(收敛后) | 量纲 |
|------|----------------|---------------|------|
| MSE | ~13.2 | ~13.0 | 有量纲（信号功率） |
| Corr | ~0.023 | ~0.003 | 无量纲（已归一化） |
| Peak | ~0.67 | ~0.056 | 无量纲（[0,1]） |

MSE与Corr的量级差 **4500倍**！这意味着`L = corr + 0.03·MSE`中MSE实际贡献87%的总loss——ε的"表观权重"与"实际重要性"完全脱节。这解释了为什么11轮实验才找到ε=0.03：**因为ε补偿的是4500倍的量级差，不是设定的权衡比**。

### 2.4.2 NMSE归一化

定义归一化MSE（NMSE）：

$$\text{NMSE} = \frac{\|\hat{\mathbf{x}} - \mathbf{s}\|^2}{\|\mathbf{s}\|^2}$$

- NMSE=0：完美重建；NMSE→1：不相关；NMSE>1：比噪声差
- 归一化后NMSE~1.1, Corr~0.02 → 量级差从4500×缩至55×

### 2.4.3 容量分配理论定权

瓶颈独立性实验（R12）证明128维足够保留GCC结构。潜空间超出128维的部分可用于重建：

| CR | 潜空间M | Corr最低占用 | 额外可分配 | R20 ε | λ_peak_max |
|----|---------|-------------|-----------|---------------|--------|
| 4 | 512 | 128 (25%) | 384 (75%) | **0.15** | 0.15 |
| 8 | 256 | 128 (50%) | 128 (50%) | **0.08** | 0.20 |
| 16 | 128 | 128 (100%) | 0 (0%) | **0.03** | 0.25 |

**最终公式**（所有CR统一，仅ε不同）：

R20当前待运行公式：

```
NMSE_mix = (1-epsilon) * NMSE_mag + epsilon * NMSE_complex
L = 1.0 * L_Corr + lambda_peak(SNR) * L_Peak + epsilon_current * NMSE_mix
```

Corr权重1.0恒定的原因：TDOA是所有CR的最终目标，瓶颈独立性保证128维就够。

### 2.4.4 λ_peak的峰值特异性理论

L_Peak直接最大化真实TDOA处的GCC幅度，比L_Corr（全GCC形状匹配）更"TDOA特异性"。容量越受限，越需要这种直接TDOA信号：

$$\lambda_{\text{peak}}(M) = 0.25 - 0.10 \cdot \frac{M - 128}{384}$$

| CR | M | λ_peak | 物理意义 |
|----|---|--------|---------|
| 4 | 512 | **0.15** | 容量充裕，Peak辅助Corr即可 |
| 8 | 256 | **0.20** | 中等容量，Peak适度增强 |
| 16 | 128 | **0.25** | 容量受限，Peak提供关键TDOA信号 |

### 2.4.4 四大核心发现

1. **TDOA精度跃升一个数量级**：CR4@-10dB从171→16（-91%）
2. **CR16瓶颈被消除**：GCC主导下128维足够保留GCC结构——"瓶颈独立性"
3. **CR排序消失是正面发现**：压缩率不再影响TDOA精度
4. **信号退化验证Fowler论断**（→见 [§1.1.1](#111-mse-失真的局限性)）：波形面目全非但TDOA精度远优于原始信号

### 2.4.5 代码实现

`train.py:train_one_fold` 当前统一使用R20固定比例混合NMSE；`main.py` 中 `CORR_WEIGHT=1.0`，每个CR由 `LOSS_CONFIG` 提供 `epsilon_mse` 和 `lambda_peak`。

### 2.4.6 方案0a：GCC峰值损失

`gcc_peak_loss_per_sample` + `adaptive_peak_lambda`（低SNR高权重）：`lambda_peak(SNR)=lambda_peak_max*sigmoid((0-SNR)/5)`。训练集与验证集均使用同一SNR自适应Peak权重。

### 2.4.7 方案0b：GCC形状保持

`gcc_torch` 可微分GCC + `MSE(norm(GCC_dae), norm(GCC_clean))`。

### 2.4.8 信息瓶颈框架（方案9 → 理论框架 🔄）

**原定位**：独立P0实现方案 → **新定位**：GCC中心损失的信息论框架

**理论基础**：信息瓶颈（Information Bottleneck, IB）理论——学习压缩表示Z使 I(Z;X) 最小化（压缩）而 I(Z;TDOA) 最大化（保留任务信息）。这正是"MSE压缩不保留TDOA信息"的严格信息论表述。

**与GCC中心损失的关系**：

| 信息瓶颈项 | GCC中心损失对应 | 含义 |
|-----------|----------------|------|
| I(Z;X) 最小化 | ε·L_mse（退化正则项） | 压缩表示的信息量约束 |
| I(Z;TDOA) 最大化 | L_corr + L_peak（GCC域代理） | 任务相关信息保留 |
| β 参数 | λ, ε | 压缩-精度权衡 |

GCC中心损失是信息瓶颈的**操作化近似**——在GCC域而不是信息论域实现压缩-精度权衡。VIB（变分信息瓶颈）为GCC中心损失提供了严格的理论框架，但作为独立实现方案存在变分推断复杂度高的风险。因此保留其理论价值但不作为独立实现方向推进。

## 2.5 P0：频带选择性压缩（方案7 ⬆️ P1→P0）

**来源**：<a href="#ref-10">[10] Weiss</a>（→见 [§1.1.3](#113-率失真理论的次优性)）+ <a href="#ref-22">[22] Baroughi</a> + <a href="#ref-24">[24] Gu</a>（→见 [§1.1.2](#112-fisher-信息失真准则)）

### 2.5.1 核心理论依据

<a href="#ref-10">[10] Weiss</a> 完整阅读揭示**速率诱导的机制转换**：压缩率超过临界值后，RD-最优压缩系统性丢弃高频段，定位精度发生相变式崩溃。频带选择性压缩不是可选项而是**必选项**。

### 2.5.2 双路径实现

**路径A（快速验证——Baroughi 2009 DFT相位路径）**：
```
输入 → DFT → 仅保留相位 → 发往融合中心 → 评估TDOA精度损失
```
Baroughi <a href="#ref-22">[22]</a> 证明仅发DFT相位可在原始压缩基础上额外实现约50%的数据压缩，同时保持TDOA精度。

**路径B（完整实现——频带注意力DAE）**：
```
阶段1（离线）：信号→STFT→Fisher信息频段评估→权重w(f)
阶段2（在线）：FFT→重要频段(高潜空间)→非重要频段(低潜空间)→IFFT
```

### 2.5.3 工程可行性支持

<a href="#ref-24">[24] Gu</a> 证明CS测量核可在**离线阶段**以GMM学习信号结构后优化，不影响在线编码效率——验证了方案7分阶段（离线评估+在线应用）的工程可行性。Fowler <a href="#ref-5">[5]</a> 的STFT评估+滤波器组合架构提供了频段权重计算的具体方法。

**预期效果**：TDOA精度提升20-50%，可能恢复CR排序。

## 2.7 P2：自适应CR选择（方案6 ⬆️ P4→P2）

**来源**：<a href="#ref-57">[57] Kirmaz</a> 锚点选择实证 + <a href="#ref-56">[56] Kirmaz</a> TDoA vs ToA效率分析

**核心思路**：根据信道条件（多径丰富度、SNR、簇分布）动态选择最优CR。当GCC中心损失消除CR排序后（R11实验证实），CR的选择聚焦于通信带宽节省与TDOA精度的实用权衡而非精度本身。

**现有依据**：
- <a href="#ref-57">[57] Kirmaz</a> 锚点选择可减少 **25%** 定位锚点同时保持/提升精度——验证了"资源自适应"策略的工程可行性
- R11实验：全CR=21/21 → CR不再影响TDOA精度 → CR选择问题从"哪个CR精度最高"变为"带宽-鲁棒性权衡"

**技术路线**：
1. 离线阶段：在多个CR下训练DAE，评估每个CR的带宽-精度-鲁棒性曲线
2. 在线阶段：根据当前信道条件（基于DAE信号估计的多径特征）选择最优CR

## 2.13 归档：Fisher信息损失（方案8）

**归档理由**：经互谱匹配(β=0.005, R7)和RMS带宽(β=0.1, R8)两轮实验，FI损失未提供超越GCC相关性损失的增量。GCC损失本身就是Fisher信息保持的操作化实现——FI作为独立损失是冗余的。
