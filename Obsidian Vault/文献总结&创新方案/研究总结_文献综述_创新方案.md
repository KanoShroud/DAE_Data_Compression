#### 1.3 创新贡献：GCC 相关性损失

**问题发现**：MSE 训练的 DAE 在低 SNR 下 TDOA RMSE 高于 Raw（无 DAE）。

**根因分析**：
- MSE 优化逐点波形误差，不保证保留互相关峰位置
- DAE 去噪引入微小波形畸变，破坏 GCC 依赖的互相关结构
- 诊断脚本验证：DAE 主峰幅度仅为 Raw 的 3.7%

**解决方案**：在 MSE 损失基础上添加 GCC 互相关正则项：

```
L = MSE(DAE(X₁), Clean₁) + MSE(DAE(X₂), Clean₂) + λ · MSE(GCC_norm(DAE), GCC_norm(Clean))
```

**技术实现**：
- `generate_paired_training_dataset()`: 生成配对数据（X₁, X₂ 同信道同噪声）
- `gcc_torch()`: PyTorch 可微分 GCC 计算
- GCC 归一化到峰值=1，关注峰形状和位置而非幅度
- Clean 信号 GCC 在 `torch.no_grad()` 下计算，节省梯度开销
- 合并 X₁/X₂ 为单次前向传播，训练加速 ~30%

**效果验证**：

| λ | DAE 优于 Raw 的 SNR 点数 | CR 排序正确率 |
|---|-------------------------|---------------|
| 0（纯 MSE） | 0/16 | ~5/16 |
| 0.1 | 6/16 | ~7/16 |
| **0.3** | **20/21** | **20/21** |
| 0.5 | 6/16 | ~7/16 |

### 2. 经典数据压缩方法：Fowler 系列工作

Fowler 及其合作者在 2000-2010 年间系统研究了面向 TDOA/FDOA 定位的数据压缩问题，奠定了该领域的理论基础。

#### 2.1 MSE 失真的局限性

Fowler [1] 首次指出 MSE 失真准则在 TDOA/FDOA 定位中的局限性：

**核心观点**（从全文提取）：
- MSE 失真与 TDOA 估计精度之间的关系较弱
- 增加 MSE 可能不影响参数精度（如相位误差不影响幅度）
- TDOA 精度还取决于信号的 RMS 带宽/持续时间和 TDOA/FDOA 的相对有用性

**MSE 失真的两个根本缺陷**：
1. MSE 增加不一定影响参数精度（如只改变相位不改变幅度）
2. 参数精度还取决于信号的 RMS 带宽/持续时间，MSE 无法捕捉这些因素

**补充证据**（Fowler 2000）：
- 抽取和量化的组合可以满足单独量化无法满足的数据传输时间要求
- 当量化方法能满足要求时，抽取/量化组合可以获得更好的 TDOA 精度
- 关键洞察：TDOA 精度取决于信号的 RMS 带宽，因此可以显著减少数据量而不影响 RMS 带宽的压缩技术有很大潜力

**对当前项目的启示**：
- DAE 用 MSE 训练，可能保留了对信号重建重要但对 TDOA 不重要的信息
- 应考虑使用面向 TDOA 的失真准则（如 Fisher 信息）
- 可以借鉴抽取/量化组合思想，在 DAE 中引入频带选择性

**关键论文**:
- [Fowler 2001a] M. Fowler, "New distortion measures for data compression for emitter location," in *Proc. 2001 Asilomar Conf.*, vol. 1, pp. 658-662. ✅ 有PDF
- [Fowler 2000a] M. Fowler, "Decimation vs. quantization for data compression in TDOA systems," in *Proc. SPIE*, vol. 4122, pp. 56-67, 2000. ✅ 有PDF

#### 2.2 基于 Fisher 信息的压缩

Fowler 和 Chen [2] 提出了基于 Fisher 信息的数据压缩方法：

**技术原理**（从全文提取）：
- Fisher 信息矩阵量化了观测数据对参数估计的信息量
- 压缩后保留 Fisher 信息最大的数据分量
- 通过操作率失真框架优化比特分配
- 使用 Lagrange 乘子法的整数优化版本确定最优操作点

**关键结果**：
- Fisher 信息方法在 TDOA 和 FDOA 估计中均优于 MSE 方法
- 可以用变换编码有效捕捉压缩对估计精度的影响
- 支持在操作率失真框架内高效优化

**对当前项目的启示**：
- 可以用 Fisher 信息作为 DAE 训练的辅助损失
- 或者用 Fisher 信息指导压缩率选择

**关键论文**:
- [Fowler 2005a] M. Fowler and D. Chen, "Fisher-information-based data compression for estimation using two sensors," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 41, no. 3, pp. 1131-1137, Jul. 2005. ✅ 有PDF
- [Baroughi 2009] A. Baroughi and A. Shirazi, "Fisher information based signal compression in TDOA estimation application," in *Proc. 2009 CSI Comput. Conf.*, pp. 299-304. ✅ 有PDF

#### 2.3 基于 SVD 的压缩

Pourhomayoun 和 Fowler [3] 提出了基于奇异值分解（SVD）的数据压缩方法：

**技术原理**：
- 利用雷达脉冲序列的脉冲间冗余
- 通过 SVD 分解提取主要奇异向量
- 结合 Fisher 信息准则消除对 FDOA 估计不重要的脉冲

**关键论文**:
- [Pourhomayoun 2011a] M. Pourhomayoun and M. Fowler, "An SVD approach for data compression in emitter location systems," in *Proc. 2011 Asilomar Conf.*, pp. 257-261. ✅ 有PDF
- [Fowler 2010a] M. Fowler et al., "Data compression using SVD and fisher information for radar emitter location," *Signal Process.*, vol. 90, no. 7, pp. 2190-2202, Jul. 2010. ✅ 有PDF

#### 2.4 几何自适应压缩

Chen 和 Fowler [4] 提出了几何自适应数据压缩方法：

**技术原理**（从全文提取）：
- 多传感器系统通常需要从数据中做出多个估计
- 这些多个估计通常有冲突的压缩需求
- 使用基于 Fisher 信息矩阵迹的失真度量
- 使用数值优化方法实现多个估计之间的压缩权衡

**关键发现**：
- TDOA 估计和 FDOA 估计对压缩有不同的需求
- 存在 TDOA 精度和 FDOA 精度之间的基本权衡
- 几何自适应压缩方案可以根据传感器-目标几何关系调整压缩策略

**对当前项目的启示**：
- 多个估计任务（如 TDOA + 定位）可能有冲突的压缩需求
- 可以借鉴几何自适应思想，根据信道条件调整压缩策略

**关键论文**:
- [Chen 2005] D. Chen and M. Fowler, "Geometry-adaptive data compression for TDOA/FDOA location," in *Proc. ICASSP 2005*, vol. 4, pp. iv/1069-iv/1072. ✅ 有PDF
- [Chen 2010] D. Chen and M. Fowler, "Data compression for multi-parameter estimation for emitter location," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 46, no. 1, pp. 308-322, Jan. 2010. ✅ 有PDF

#### 2.5 非 MSE 小波压缩

Fowler [5] 提出了基于小波变换的非 MSE 数据压缩方法：

**技术原理**：
- 使用小波包变换进行信号分解

**关键论文**:

#### 2.6 抽取与量化的权衡

Fowler [6] 分析了抽取（decimation）和量化（quantization）在 TDOA 系统中的权衡：

**核心观点**：
- TDOA 精度取决于信号的 RMS 带宽
- 抽取会降低 RMS 带宽，但减少数据量
- 量化不改变 RMS 带宽，但引入量化噪声
- 存在最优的抽取-量化平衡点

**关键论文**:
- [Fowler 2000a] M. Fowler, "Decimation vs. quantization for data compression in TDOA systems," in *Proc. SPIE*, vol. 4122, pp. 56-67, 2000. ✅ 有PDF

#### 2.7 粗量化

Fowler [7] 分析了粗量化对相干定位系统的影响：

**技术贡献**：
- 分析了两种块自适应量化方案（R/I 和 M/P）
- 推导了量化后 SNR 和相关后 SNR 的关系
- 提出了 M/P 方案的最优比特分配规则

**关键论文**:
- [Fowler 2000b] M. Fowler, "Coarse quantization for data compression in coherent location systems," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 36, no. 4, pp. 1269-1278, Oct. 2000. ✅ 有PDF

#### 2.8 交叉模糊函数压缩

Pourhomayoun 和 Fowler [8] 提出了基于交叉模糊函数（CAF）特性的数据压缩方法：

**技术原理**（从全文提取）：
- CAF 包含 TDOA/FDOA 估计所需的全部信息
- 直接压缩 CAF 而非原始信号
- 推导 CAF 的有益特性和特征，用于实现更好的 CAF 压缩
- 利用 CAF 的结构特性（如对称性、峰值位置）优化压缩

**对当前项目的启示**：
- CAF 压缩比原始信号压缩更高效
- 可以考虑在 DAE 中直接压缩 CAF 而非原始信号

**关键论文**:

### 3. 基于信息论的压缩方法

#### 3.1 率失真理论的次优性

Weiss [9] 推导了分布式定位中率失真最优压缩的精度极限：

**核心发现**：
- 传统率失真最优压缩（最小化 MSE）在定位任务中是次优的
- MSE 失真准则可能消除定位信息（如信号的高频分量）
- 简单的频带选择性压缩方案可以大幅优于率失真压缩

**数学框架**：
- 使用高斯率失真测试信道模型
- 结合 Whittle 谱 Fisher 信息表征
- 获得显式的频域 Cramér-Rao 下界

**关键定理**（从全文提取）：
- 率失真最优压缩在 MSE 准则下，会优先保留信号能量最大的频段
- 但定位信息可能集中在能量较低的频段（如高频分量提供时间分辨率）
- 因此 RD-optimal 压缩可能消除定位信息，导致定位精度下降数个数量级

**关键结果**：
- 两频带、两电平特化给出闭式表达
- 简单的频带选择性方案在相同比率下可优于 RD 压缩数个数量级
- 启发了面向定位的压缩设计（localization-aware compression）

**对当前项目的启示**：
- MSE 损失训练的 DAE 可能保留了对信号重建重要但对 TDOA 不重要的信息
- 应考虑使用面向 TDOA 的失真准则（如 Fisher 信息或 GCC 结构）

**关键论文**:
- [Weiss 2026] A. Weiss, "On the suboptimality of rate-distortion-optimal compression: fundamental accuracy limits for distributed localization," *IEEE Signal Process. Lett.*, vol. 33, pp. 1566-1570, 2026. ✅ 有PDF

#### 3.2 信息论 CS 核优化

Gu 和 Goodman [10] 提出了基于信息论的压缩感知核优化方法：

**技术原理**：
- 使用高斯混合模型建模先验概率

- 推导贝叶斯 Cramér-Rao 下界

### 4. 量化压缩方法

**技术原理**（从全文提取）：

- 1-bit 量化在某些场景下可能足够

**关键论文**:

#### 6.2 神经互相关（PNCC）

Dominguez [24] 提出了成对神经互相关（Pairwise Neural Cross-Correlation, PNCC）方法：

**技术原理**：
- 训练一个 Transform Network 对信号对进行变换
- 变换后的信号与未变换的伙伴信号在真实 TDOA 位置产生高峰
- 损失函数：最大化真实延迟位置的互相关值
- 关键创新：不需要真实互相关信号作为标签，只需真实 TDOA 峰位置

**训练架构**：
```
输入: (α₁, α₂) 含噪信号对
      ↓
Transform Network T(·)
      ↓
(T(α₁), α₂) 和 (α₁, T(α₂))
      ↓
最大化 cross-correlation @ true λ
```

**关键结果**：
- TDOA 估计 MAE 降低 49.4%
- 多普勒频移估计 MAE 降低 27.2%
- 载波频率估计 MAE 降低 76.3%
- 定位 MAE 降低 22.8%

**与我们项目的对比**：
- PNCC 学习信号变换，我们学习信号去噪
- PNCC 的损失函数直接优化互相关峰值，我们的 GCC 相关性损失类似但实现不同
- PNCC 在 SNR=-20 dB 下仍能产生可见峰，说明这种方法在极低 SNR 下有效

**对当前项目的启示**：
- 可以借鉴 PNCC 的损失函数设计：直接最大化真实 TDOA 位置的互相关值
- 而非比较整个 GCC 形状（我们当前的做法）

**关键论文**:
- [Dominguez 2025] Dominguez, "Pairwise neural cross-correlation for accurate estimates in low SNR," in *Proc. MILCOM 2025*, pp. 1327-1334. ✅ 有PDF

### 7. 联合压缩-估计方法：极值编码

Weiss、Kochman 和 Wornell [32-34] 提出了极值编码方法，将数据压缩和时延估计联合优化：

- 极值编码：直接编码对 TDOA 估计最有用的信息

**编码方式**：

**挑战**：
- 未知信号相位
- 噪声的随机相位
- 原始方案不适用

**解决方案**：
- 自然但精巧的方案扩展
- 不同的统计分析（非高斯分布的极值）
- 为 RF 应用铺平道路

#### 7.3 理论分析

### 8. 直接定位中的压缩

#### 8.1 DPD 概述

直接定位（DPD）方法通过直接处理原始信号估计源位置，避免了传统两步方法的信息损失。然而，DPD 要求所有传感器的原始数据传输至融合中心，通信开销巨大。

#### 8.2 CS-DPD

**技术原理**：
- 利用 Hadamard 矩阵性质
- 在压缩测量域直接估计源位置
- 无需信号重构和 TDOA 参数提取

**关键论文**:
- [You 2023] Z. You et al., "Direct position determination using compressive sensing measurements without reconstruction," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 59, no. 2, pp. 2036-2043, Apr. 2023. ✅ 有PDF

#### 8.3 UAV-DPD

**Zhu 等人 [36]** 提出了基于双 UAV 的同步误差 DPD 方法：

**技术原理**：
- 考虑同步误差和多径环境
- 提出两种 DPD 代价函数
- 在复杂电磁环境下实现高精度定位

**关键论文**:
- [Zhu 2026] Zhu et al., "Direct position determination using dual UAVs with synchronization error in multipath environments," *IEEE Trans. Aerosp. Electron. Syst.*, vol. 62, pp. 2871-2882, 2026. ✅ 有PDF

## 第三部分：创新方案

### 10. 研究空白与创新方向

#### 10.1 当前研究空白（基于全文阅读的深入分析）

1. **MSE 损失的根本缺陷**（Weiss 2026 证实）：MSE 失真准则会优先保留信号能量最大的频段，但定位信息可能集中在能量较低的频段。DAE 用 MSE 训练，可能保留了对信号重建重要但对 TDOA 不重要的信息。

2. **GCC 形状匹配的局限性**（Dominguez 2025 启示）：我们的 GCC 相关性损失比较整个 GCC 形状，但 PNCC 证明直接最大化真实 TDOA 位置的互相关值更有效。当前方法可能在不重要的 GCC 区域浪费了优化能力。

3. **理论分析不足**：缺乏面向定位的深度学习压缩的理论性能界。Weiss 2026 推导了 RD-optimal 压缩的 CRLB，但 DAE 的理论性能界未知。

4. **信道模型简化**：大多数仿真使用简化信道模型，缺乏真实环境验证。论文使用 Wireless InSite 城市场景，我们使用 Saleh-Valenzuela 模型。

5. **CR 自适应缺失**：现有方法使用固定压缩率，缺乏根据信道条件动态调整的机制。

#### 10.2 创新方案（基于全文阅读更新，按可行性和创新性排序）

**方案 0：PNCC 启发的 TDOA 峰值损失（可行性：中，创新性：高）**

**来源**：Dominguez 2025 的 PNCC 方法

**目标**：直接最大化真实 TDOA 位置的互相关值，而非比较整个 GCC 形状。

**技术路线**：
```
L_peak = -|GCC(DAE(X₁), DAE(X₂))|² @ true_tdoa
```

**与当前 GCC 相关性损失的对比**：
- 当前：比较整个 GCC 形状（MSE loss on normalized GCC）
- PNCC 启发：只关注真实 TDOA 位置的峰值大小

**优势**：
- 更直接地优化 TDOA 估计目标
- 避免在不重要的 GCC 区域浪费优化能力
- Dominguez 2025 证明在 SNR=-20 dB 下仍有效

**方案 1：自适应 λ 策略（可行性：高，创新性：中）**

**目标**：根据 SNR 动态调整 λ，低 SNR 更重视相关性。

**技术路线**：
```
λ(SNR) = λ₀ · σ((SNR_threshold - SNR) / temperature)
```

**详细步骤**：
1. 在训练时估计当前 batch 的 SNR
2. 根据 SNR 计算 λ
3. 低 SNR → λ 大（更重视 GCC 结构）
4. 高 SNR → λ 小（更重视波形重建）

**创新点**：
- 自适应权重调整策略
- 理论推导最优 λ 与 SNR 的关系
- 在不同信道条件下自动优化

**实验设计**：
- 对比固定 λ 和自适应 λ 的性能
- 分析不同 SNR 阈值的影响
- 在多种信道模型下验证

**预期效果**：低 SNR 性能提升 10-20%

**方案 2：TDOA-Aware 损失函数（可行性：中，创新性：高）**

**目标**：直接优化 TDOA 估计误差，而非 GCC 形状匹配。

**技术路线**：
```
L_tdoa = (soft_argmax(GCC(DAE(X₁), DAE(X₂))) - true_tdoa)²
```

**详细步骤**：
1. 实现可微分软 argmax：
   ```
   soft_argmax = Σ(τ · softmax(GCC(τ) / temperature))
   ```
2. 计算 TDOA 损失
3. 与 MSE 损失联合优化：
   ```
   L = MSE + α · L_tdoa
   ```
4. 调优 temperature 和 α 参数

**创新点**：
- 直接优化目标函数（TDOA 精度）
- 可微分软 argmax 实现端到端训练
- 与 MSE 损失联合优化，平衡去噪和 TDOA 精度

**实验设计**：
- 对比 MSE、GCC 相关性损失、TDOA-aware 损失的性能
- 分析 temperature 参数的影响
- 在不同 SNR 范围下验证

**预期效果**：TDOA RMSE 进一步降低 20-30%

**方案 3：多任务学习（可行性：中，创新性：高）**

**目标**：DAE 同时去噪和估计 TDOA（联合优化）。

**技术路线**：
```
共享编码器 → 分支1：解码器 → 去噪信号
           → 分支2：TDOA 头 → TDOA 估计
L = MSE(denoised, clean) + α · MSE(tdoa, true_tdoa)
```

**详细步骤**：
1. 设计共享编码器架构
2. 设计去噪解码器分支
3. 设计 TDOA 估计分支
4. 联合训练两个任务
5. 分析任务间的相互促进效果

**创新点**：
- 共享特征表示的多任务架构
- 去噪和 TDOA 互相促进
- 端到端训练无需分阶段优化

**实验设计**：
- 对比单任务和多任务的性能
- 分析共享特征的有效性
- 在不同信道条件下验证

**预期效果**：去噪和 TDOA 精度同时提升

**方案 4：与极值编码对比（可行性：高，创新性：中）**

**目标**：将当前 DAE 方法与 Weiss 的极值编码方法进行系统对比。

**详细步骤**：
1. 复现极值编码方法
2. 在相同信道和 SNR 条件下对比
3. 分析各自优势和适用场景
4. 探索两种方法的互补性

**创新点**：
- 首次系统对比深度学习压缩与信息论压缩
- 揭示两种方法的互补性
- 为实际系统设计提供指导

**实验设计**：
- 在多种信道模型下对比
- 分析不同压缩率下的性能
- 评估计算复杂度

**预期效果**：明确两种方法的适用场景

**方案 5：信道估计辅助（可行性：中，创新性：中）**

**目标**：DAE 同时输出信道估计，辅助 TDOA。

**技术路线**：
```
DAE → (denoised_signal, channel_estimate)
channel_estimate → 用于 GCC 加权
```

**详细步骤**：
1. 设计信道估计分支
2. 训练信道估计任务
3. 将信道估计用于 GCC 加权
4. 分析信道估计对 TDOA 精度的影响

**创新点**：
- 信道感知的 GCC 加权
- 利用信道信息提升 TDOA 精度
- 端到端训练

**预期效果**：在复杂信道下提升 TDOA 精度

**方案 6：CR 自适应选择（可行性：高，创新性：低）**

**目标**：根据信道条件动态选择最优 CR。

**方案 7：面向定位的频带选择性压缩（可行性：中，创新性：高）**

**来源**：Weiss 2026 的理论发现

**目标**：保留对 TDOA 估计最重要的频段，而非均匀压缩。

**方案 8：基于 Fisher 信息的损失函数（可行性：中，创新性：高）**

**来源**：Fowler 2005, Chen 2010

**目标**：用 Fisher 信息作为 DAE 训练的损失函数，直接优化参数估计精度。

**技术路线**：
```
L = MSE + β · L_fisher
L_fisher = -log(det(Fisher_information_matrix))
```

**理论依据**：
- Fowler 2005 证明 Fisher 信息方法优于 MSE 方法
- Chen 2010 证明多个估计任务有冲突的压缩需求
- Fisher 信息直接量化数据对参数估计的信息量

**优势**：
- 直接优化参数估计精度
- 可以处理多参数估计的权衡
- 有坚实的理论基础

**预期效果**：TDOA 精度提升 20-40%

**理论依据**：
- Weiss 2026 证明 MSE 最优压缩会消除定位信息
- 定位信息集中在信号的某些频段（如高频分量提供时间分辨率）
- 简单的频带选择性方案可优于 RD 压缩数个数量级

**技术路线**：
```
输入信号 → FFT → 频段重要性评估 → 保留关键频段 → 压缩 → 传输
```

**详细步骤**：
1. 分析不同频段对 TDOA 估计的贡献（通过 Fisher 信息）
2. 设计频段重要性评估模块
3. 保留关键频段，压缩非关键频段
4. 与 DAE 方法对比

**创新点**：
- 首次将 Weiss 2026 的理论发现应用于深度学习压缩
- 面向定位的频段选择策略
- 理论指导的压缩设计

**预期效果**：在相同压缩率下，TDOA 精度提升 20-50%

**详细步骤**：
1. 训练多个 CR 的 DAE
2. 设计 CR 选择器
3. 根据信道特征选择最优 CR
4. 分析不同信道下的最优 CR

**创新点**：
- 自适应压缩率选择
- 根据信道条件优化压缩-精度权衡

**预期效果**：在不同信道下自动选择最优压缩率

### 11. 联合创新方案实现

方案 1（自适应 λ）、方案 2（TDOA-Aware 损失）、方案 3（多任务学习）可以自然组合，形成一个完整的系统。

#### 11.1 联合架构

```
输入信号 X_noisy
      ↓
  共享编码器 (Encoder)
      ↓
   潜空间表示 z
      ↓
  ┌───┴───┐
  ↓       ↓
去噪解码器  TDOA 头
  ↓       ↓
X_denoised τ̂
  ↓       ↓
MSE损失   TDOA损失
  ↓       ↓
  └───┬───┘
      ↓
  自适应 λ 加权
      ↓
    总损失 L
```

#### 11.2 损失函数

```
L = λ(SNR) · MSE(X_denoised, X_clean) + (1-λ(SNR)) · L_tdoa

其中：
λ(SNR) = σ((SNR_threshold - SNR) / temperature)

L_tdoa = (τ̂ - τ_true)²

τ̂ = soft_argmax(GCC(X_denoised₁, X_denoised₂))
```

#### 11.3 模型结构

```python
class MultiTaskDAE(nn.Module):
    """多任务 DAE：去噪 + TDOA 估计"""
    
    def __init__(self, cr=8, max_lag=512):
        super().__init__()
        
        # 共享编码器（与原 DAE 相同）
        self.enc = nn.Sequential(
            ComplexConv1d(1, 32, 10, 6, 2), ComplexBatchNorm1d(32), nn.ReLU(),
            ComplexConv1d(32, 32, 5, 2, 2), ComplexBatchNorm1d(32), nn.ReLU(),
            ComplexConv1d(32, 64, 5, 2, 2), ComplexBatchNorm1d(64), nn.ReLU(),
            ResidualBlock(64), ResidualBlock(64)
        )
        self.feature_len = 43
        self.latent_dim = 2048 // cr
        self.fc_enc = ComplexLinear(128 * 43 // 2, self.latent_dim // 2)
        
        # 去噪解码器（与原 DAE 相同）
        self.fc_dec = ComplexLinear(self.latent_dim // 2, 128 * 43 // 2)
        self.dec_res = nn.Sequential(ResidualBlock(64), ResidualBlock(64))
        self.dec_conv = nn.Sequential(
            ComplexConvTranspose1d(64, 32, 5, 2, 2, output_padding=0),
            ComplexBatchNorm1d(32), nn.ReLU(),
            ComplexConvTranspose1d(32, 32, 5, 2, 2, output_padding=1),
            ComplexBatchNorm1d(32), nn.ReLU(),
            ComplexConvTranspose1d(32, 1, 10, 6, 2, output_padding=4)
        )
        
        # TDOA 头
        self.tdoa_head = TDOAHead(self.latent_dim, max_lag)
    
    def encode(self, x):
        b = x.size(0)
        z = self.fc_enc(self.enc(x).view(b, -1))
        return z
    
    def decode(self, z):
        b = z.size(0)
        return self.dec_conv(self.dec_res(self.fc_dec(z).view(b, 128, -1)))
    
    def forward(self, x):
        z = self.encode(x)
        x_denoised = self.decode(z)
        tdoa, logits = self.tdoa_head(z)
        return x_denoised, tdoa, logits, z
```

#### 11.4 TDOA 头设计

```python
class TDOAHead(nn.Module):
    """从潜空间直接估计 TDOA"""
    def __init__(self, latent_dim, max_lag=512):
        super().__init__()
        self.fc = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, max_lag * 2 + 1)
        )
        self.max_lag = max_lag
    
    def forward(self, z):
        logits = self.fc(z)
        tau = torch.softmax(logits, dim=-1)
        indices = torch.arange(-self.max_lag, self.max_lag + 1, 
                              device=z.device, dtype=torch.float32)
        tdoa = (tau * indices).sum(dim=-1)
        return tdoa, logits
```

#### 11.5 自适应 λ 模块

```python
class AdaptiveLambda(nn.Module):
    """根据 SNR 自动调整 λ"""
    def __init__(self, snr_threshold=0.0, temperature=5.0):
        super().__init__()
        self.snr_threshold = nn.Parameter(torch.tensor(snr_threshold))
        self.temperature = nn.Parameter(torch.tensor(temperature))
    
    def forward(self, snr):
        lambda_val = torch.sigmoid(
            (self.snr_threshold - snr) / self.temperature
        )
        return lambda_val
```

#### 11.6 完整损失函数

```python
class MultiTaskLoss(nn.Module):
    """多任务损失：MSE + TDOA + GCC 相关性"""
    
    def __init__(self, snr_threshold=0.0, temperature=5.0, 
                 alpha_tdoa=1.0, alpha_corr=0.3):
        super().__init__()
        self.adaptive_lambda = AdaptiveLambda(snr_threshold, temperature)
        self.mse_loss = nn.MSELoss()
        self.alpha_tdoa = alpha_tdoa
        self.alpha_corr = alpha_corr
    
    def forward(self, x_denoised, x_clean, tdoa_pred, tdoa_true, 
                logits, snr, x1_clean, x2_clean, x1_denoised, x2_denoised):
        # 1. MSE 损失
        loss_mse = self.mse_loss(x_denoised, x_clean)
        
        # 2. TDOA 损失（直接优化 TDOA 精度）
        loss_tdoa = self.mse_loss(tdoa_pred, tdoa_true)
        
        # 3. GCC 相关性损失（保留互相关结构）
        gcc_clean = gcc_torch(x1_clean[:, 0, :], x1_clean[:, 1, :],
                             x2_clean[:, 0, :], x2_clean[:, 1, :])
        gcc_denoised = gcc_torch(x1_denoised[:, 0, :], x1_denoised[:, 1, :],
                                x2_denoised[:, 0, :], x2_denoised[:, 1, :])
        gcc_clean_n = gcc_clean / (torch.max(torch.abs(gcc_clean), 
                                           dim=-1, keepdim=True)[0] + 1e-9)
        gcc_denoised_n = gcc_denoised / (torch.max(torch.abs(gcc_denoised), 
                                                   dim=-1, keepdim=True)[0] + 1e-9)
        loss_corr = self.mse_loss(gcc_denoised_n, gcc_clean_n)
        
        # 4. 自适应加权
        lambda_val = self.adaptive_lambda(snr)
        lambda_mean = lambda_val.mean()
        
        # 5. 总损失
        loss_total = (lambda_mean * loss_mse + 
                     (1 - lambda_mean) * self.alpha_tdoa * loss_tdoa +
                     self.alpha_corr * loss_corr)
        
        return loss_total, {
            'mse': loss_mse.item(),
            'tdoa': loss_tdoa.item(),
            'corr': loss_corr.item(),
            'lambda': lambda_mean.item()
        }
```
