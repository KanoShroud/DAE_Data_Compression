# 研究总结

更新时间：2026-07-16

本文档用于承接并重组 `Obsidian Vault/文献总结&创新方案/研究总结_文献综述_创新方案.md` 中“研究总结”部分，同时补充 2026-07 以来复现基线、传统对比方法、压缩域 direct TDOA、双站异构选频与伪补全、PFRS 固定掩码等路线的完整研究进展。

## 1. 当前研究定位

本项目最初目标是复现 Chen 等 2025 年 TVT 论文中的 DAE 数据压缩协作定位方法。后续实验发现，在无法获得 Wireless InSite 原始数据和论文全部实现细节的条件下，严格复现论文曲线不可完全保证。因此项目分成两条轨道：

| 轨道 | 目标 | 当前状态 |
|---|---|---|
| 论文近似复现 | 建立 Chen-style DAE、DFT、Hadamard、PCA 等基线，统一 urban8 仿真、all-pair WLS 和 TDOA/定位评估 | v3.1 已冻结为近似复现基线 |
| 创新验证 | 在相同数据和评估链路下，探索比传统压缩基线更适合 TDOA 的压缩方法 | V5/Shared64 已冻结为基线或消融；固定掩码 PFRS 已完成 `NO_GO + FIXED_MASK_SATURATED` 证书；PASR-TDOA v1 的正式主动逐层验证为 `NO_GO`，当前进入动作准则与停止证书重审 |

当前不再把“是否超过 Raw”作为创新方法的首要门槛。Raw 没有压缩，不是同等通信资源约束下的方法。创新方法的主要比较对象是 DAE-CR16、DFT/Hadamard/PCA、Cao、Zhai 等压缩或压缩域 TDOA 方法。

## 2. 论文复现基线

### 2.1 Chen-style DAE 复现轨道

| 项目 | 内容 |
|---|---|
| 创新/复现思想 | 复现 Chen 等论文中“DAE 压缩-重构-UAV 协作定位”的主链路 |
| 理论依据 | DAE 通过低维 latent 去噪与压缩，接收端重构 waveform 后用 TDOA/GCC 定位 |
| 实现方案 | `paper_repro` / v3.1：MSE-only DAE，CR=4/8/16，urban8 近似城市场景，fixed eval set，all-pair WLS，final retrain |
| 关键修正 | fixed eval set、snapshot-level 生成、all-pair TDOA、multi-start WLS、noisy RMS 归一化、固定 200 epoch final |
| 优点 | 时频域恢复可读性好；CR 越小通常重构越好；可作为论文复现基线 |
| 缺点 | 不是 Wireless InSite 数据；当前 Raw 高 SNR 很强；DAE 低 SNR 不一定全 CR 超 Raw；训练时间长 |
| 性能结论 | v3.1 已明显接近 Chen 论文趋势，但并非严格复现。高 SNR 下 Raw 接近 Clean，低 SNR 只有 CR4 更接近论文预期 |

### 2.2 传统与强基线方法

| 方法 | 论文/来源定位 | 当前实现 | 优点 | 缺点/风险 | 当前性能理解 |
|---|---|---|---|---|---|
| Raw | 未压缩输入 | noisy waveform 直接 GCC/WLS | 无压缩损失，公平评估上限之一 | 不满足压缩通信约束 | 高 SNR 常接近 Clean，不应作为创新压缩方法必须超越的硬门槛 |
| Clean oracle | 无噪 clean waveform | clean GCC/WLS | 判断噪声和求解器下限 | 非实际方法 | 用于确认定位器和几何条件 |
| Geometry oracle | 真实几何 TDOA | delay_float 直接 WLS | 判断几何/WLS 下限 | 非实际方法 | 若它不稳定，说明定位求解或几何病态 |
| DFT Chen-style | Chen Fig6 传统基线 | 频域保留固定数量频点，direct cross-spectrum / 可选 recon 消融 | 简单、可解释、无需训练 | 频点选取不任务自适应 | 严格复现轨道保留传统 DFT，创新轨道可用更强 DFT 变种作对比 |
| Hadamard / Salari | Salari 部分 Hadamard 采样 | block row selection + 伪重构/GCC | 符合参考文献行选取规则 | 高 SNR 表现不一定随 SNR 改善；随机/Sequency 无论文依据已降级 | 主图保留论文有据版本，其他变体不再作为主结论 |
| PCA | Chen 引用传统基线 | 训练样本 PCA 压缩/重构 | 经典压缩基线 | 对非平稳 TDOA 信息不敏感 | 高 SNR 仍可能较差，符合“非任务感知压缩”定位 |
| Cao2017 / DFT-AML | DFT 压缩域 TDOA | direct frequency-domain likelihood/AML 近似 | 任务导向，不依赖重构 | 对频点、相位和似然实现敏感 | 可作为强 direct baseline |
| Cao2020 | 频域相关/压缩定位思路 | 当前为近似代理实现 | 提供更强传统方法参照 | 与原文仍有简化差异 | 需在论文中清楚标注实现差异 |
| Zhai CRLB | CRLB/Fisher 频点选择 | 依据频点对时延 Fisher 信息贡献选点 | 理论清晰，是强基线 | 理论最优依赖信号/噪声/模型假设，离散实现可能有偏 | 某些 SNR 区间可强于 Raw，说明其是创新方案必须面对的强基线 |
| Zhai phase-superposition | 频域相位叠加思想 | 已补充 direct 变体 | 有任务导向理论价值 | 当前实现性能弱，可能与原文细节未完全一致有关 | 当前不作为主创新对手，但保留为强基线诊断 |

## 3. 已尝试创新方案总览

### 3.1 Loss-level DAE：MSE/GCC/Peak/R20 系列

| 项目 | 内容 |
|---|---|
| 创新思想 | 在 DAE 训练损失中加入 GCC 相关性、peak loss、SNR 自适应权重，使 latent 不只服务 waveform MSE，也服务 TDOA |
| 理论依据 | TDOA 由互相关峰位置决定，MSE 最优不等于定位最优；低 SNR 下 peak prior 可提供物理约束 |
| 实现方案 | 先后尝试 CR-specific loss、NMSE 归一化、包络 NMSE、复数 NMSE alpha blend、固定混合 NMSE、R20/R20.1 目标一致性 |
| 优点 | 验证了“任务损失可以显著改善 GCC/TDOA”；暴露了 MSE 与 TDOA 梯度冲突 |
| 缺点 | 容易产生窄带假信号、伪峰、CR 无区分度；额外维度未稳定转化为重建质量 |
| 性能结论 | 能让 TDOA/定位比纯 MSE 更强，但无法形成稳定 CR4 > CR8 > CR16 的可信创新结论 |

### 3.2 Fisher/导数/高频损失

| 项目 | 内容 |
|---|---|
| 创新思想 | 用导数或 Fisher 加权强化高频边缘，避免 MSE 低通化破坏 TDOA |
| 理论依据 | 时延 CRLB 与信号有效带宽/RMS bandwidth 相关，高频边缘对时延更敏感 |
| 实现方案 | 尝试互谱匹配、RMS 带宽保持、DFT-Fisher 频点选择和 Fisher-weighted spectral loss |
| 优点 | 理论解释强，可作为论文动机 |
| 缺点 | 直接高频硬选或零填充重构会破坏 GCC 主峰；加入导数损失会加剧梯度内战 |
| 性能结论 | 作为独立 loss/伪重构方法未成功，但保留为“任务感知频点选择”的理论来源 |

### 3.3 FrequencySelectiveDAE / FreqDAE v1-v3

| 项目 | 内容 |
|---|---|
| 创新思想 | 把任务先验前移到模型结构，在频域学习选择或强调 TDOA 相关频带 |
| 理论依据 | 时域 waveform decoder 同时承担重建和定位，容易梯度冲突；频域可显式控制带宽和相位信息 |
| 实现方案 | v1：可学习频域 soft pre-emphasis + DAE；v2/v2.1：修改 loss 与 pair-aware 目标；v3：嵌套 latent + task head |
| 优点 | 与文献中的频带选择、CRLB/Fisher 理论相连；比纯 loss 修改更有结构创新性 |
| 缺点 | 仍依赖 waveform decoder 或间接 GCC；多轮结果出现窄带假信号、宽峰、CR 无区分度 |
| 性能结论 | 低 SNR 偶有改善，但不能稳定超过强基线，未通过作为主创新路线的 go/no-go |

### 3.4 GeoAmbiguity / GeoHybrid DFT direct

| 项目 | 内容 |
|---|---|
| 创新思想 | 不重构 waveform，直接选择几何歧义更低的频点做 compressed-domain TDOA |
| 理论依据 | 部分频点组合的 ambiguity function 决定 TDOA 多峰风险；几何先验可减少错误时延峰 |
| 实现方案 | Geo-Ambiguity-Aware DFT Direct、GeoHybrid64、budget 对齐与补充诊断 |
| 优点 | 无训练、可解释、复杂度低；适合作为 direct baseline/消融 |
| 缺点 | 初版存在预算不公平；修正后低 SNR 排名不佳；高 SNR 仅部分场景有竞争力 |
| 性能结论 | 已冻结为 baseline/消融，不再继续调参作为主创新 |

### 3.5 V4 NestedTaskSufficientDAE / FreqDAE-v4-min

| 项目 | 内容 |
|---|---|
| 创新思想 | 用嵌套 latent 让 CR4 包含 CR8 包含 CR16，同时加入 task-sufficient 约束，使更多维度带来更好 TDOA |
| 理论依据 | 若 latent 具备嵌套充分统计量性质，通信资源增加应提升任务充分性和重建质量 |
| 实现方案 | `NestedTaskSufficientDAE / FreqDAE-v4-min` 快速模式与 CR16 诊断 |
| 优点 | 能直接回应用户最初“CR4 > CR8 > CR16”的资源分配设想 |
| 缺点 | 实验仍出现窄带假信号和 CR 无区分度，说明 waveform decoder 路线仍未解决根因 |
| 性能结论 | 未通过 go/no-go，促使项目转向 compressed-domain direct TDOA likelihood |

### 3.6 V5-A / V5-A.1：Compressed-Domain TDOA Likelihood

| 项目 | 内容 |
|---|---|
| 创新思想 | 彻底跳出“压缩后重构 waveform 再 GCC”，直接在压缩频域观测上估计 TDOA posterior |
| 理论依据 | 对 TDOA 来说，充分信息主要在两路信号的互谱相位差；重构 waveform 不是必要中间目标 |
| 实现方案 | V5-A：learnable compressed likelihood；V5-A.1：hard-bin exact likelihood + posterior calibration |
| 优点 | 轻量、可解释、无需 waveform decoder；和 DFT/CRLB 文献有直接理论联系 |
| 缺点 | 低 SNR 缺少 DAE 那类训练去噪能力；posterior top1 容易错峰 |
| 性能结论 | V5-A.1 明显优于 V5-A，但低 SNR 仍弱于 Chen DAE-CR16；为 V5-B expert mixture 奠定基础 |

### 3.7 旧 V5B-Expert64：CR11.64 历史机制诊断

| 项目 | 内容 |
|---|---|
| 创新思想 | 将不同频点选择专家的 posterior 融合，低置信时偏向稳健专家，高置信时允许高分辨专家参与 |
| 理论依据 | 压缩域 TDOA posterior 在低 SNR 下多峰；不同频点集合的 Fisher 信息、歧义函数和噪声鲁棒性不同 |
| 实现方案 | 现有 `V5B-Expert64` 融合 Power64 与 GeoHybrid64；非 oracle gating 使用 entropy、margin、variance、expert quality；输出 pair_weight 供 WLS |
| 优点 | 无 waveform decoder、可解释；机制诊断中可明显减少中高 SNR 误差和低 SNR 长尾 |
| 缺点 | **预算审计未通过**：两组频点并集为 88 个复频点/176 个实数，有效 CR=11.64，而非严格 CR16；低 SNR top1 错峰率仍高；在线实现还有逐 pair 双 expert 开销 |
| 性能结论 | 当前结果只能作为超预算机制上界，不能作为同预算论文主方法。须先重构共享 64-bin 双 expert 并重新训练、验证，才可判断是否形成 Pareto 创新。 |

### 3.8 V5-B top-K / BeamWLS 诊断

| 项目 | 内容 |
|---|---|
| 创新思想 | 不只看 posterior top1，而是检查真实 TDOA 是否落在 top-K 候选中，并尝试通过多假设 WLS 转化为定位收益 |
| 理论依据 | 低 SNR 下 posterior 常多峰；top1 可能错，但 top3/top5 仍可能包含真值，定位几何可帮助消歧 |
| 实现方案 | `diagnose_v5b_topk.py` 输出 pair 级独立局部峰及亚采样 lag；`diagnose_v5b_topk_wls.py` 做低置信度 Top3 GeoBeam，并同步保存最终 selected TDOA、定位、复杂度和 cluster bootstrap |
| 优点 | 不重训练、不改压缩 estimator；full 结果证明真实 TDOA 与定位误差同步改善，不只是构造几何自洽解 |
| 缺点 | 引入几何后端后不再是纯 pairwise estimator；低 SNR 重复 WLS 成本较高，必须做相同 solver 公平消融和独立场景泛化 |
| 已有诊断 | 低 SNR top1±1=59.3%，top3±1=71.9%，top5±1=77.4%，top5±2=81.1%，说明 posterior 中仍有信息 |
| full 结果 | 低 SNR定位 pooled RMSE `61.87 -> 54.05m`；TDOA MAE `6.882 -> 3.514 samples`；两项 snapshot-cluster CI 均严格为正；mid/high 不变 |
| 当前判断 | Top-K/GeoBeam 的机制 gate 已通过，但所依赖的 V5-B 前端为 CR11.64 超预算版本。该结论证明 posterior 候选和几何联合决策有价值，不证明严格 CR16 主方法已成功。 |

### 3.9 V5B-Shared64：严格 CR16 路线

| 项目 | 内容 |
|---|---|
| 审计事实 | Power64=64 bins，GeoHybrid64=64 bins，交集=40 bins，并集=88 bins；通信量为 176 real scalars，有效 CR=11.64。 |
| 原因 | 两个 expert 当前分别对原始 waveform 做 FFT 和选频；posterior 融合不等于共享传输，两组独占频点都必须从 UAV 端发送。 |
| 旧结果如何使用 | 保留为 over-budget upper bound、expert gating 与 Top-K solver 的机制消融；所有图和表必须显式标注 CR11.6，不进入严格 CR16 主排名。 |
| 最小修正 | 已实现共享 Budget64：40 个共同核心频点，Power/Geo 两侧各保留 12 个专属频点；并集 64，每个 expert 使用 52 bins。 |
| 正式结果 | `运行结果/压缩域TDOA_V5/20260711_154042_V5B_Shared64严格CR16`：V5B-Shared64 low/mid/high/all 定位 RMSE=`54.20/9.55/8.78/25.95m`；严格 CR16 下仍优于 DFT、Cao2017 等多数压缩基线，但整体略弱于 GeoShared52=`25.77m`，也弱于 DAE-CR16=`21.38m`。 |
| 当前解释 | 预算修正本身成功，但固定门控未适配 Shared52 专家：融合仅在低 SNR 对 Geo 有约 0.51m 小幅收益，中高 SNR 反而劣化。专属频点由历史集合均匀抽取，属于启发式 strict-budget baseline，不是理论最优联合选频。 |
| 独立多池复核 | pools 242/342/442 的 P1 结果表明，V5B 相对 GeoShared52 的 all RMSE/TDOA 配对增益为 `5.39m/0.287 samples`，CI 均严格为正；但相对 PowerShared52 无显著收益，相对 legacy Power64 的 TDOA 显著更差 `0.227 samples`。因此融合有抑制 Geo 长尾的机制价值，但尚未证明双专家比完整单专家更优。 |
| 证据边界 | 本轮 full 与训练使用同一 50-snapshot pool，只能作为同分布开发结果；旧权重、旧 top-K rows 和旧复杂度结果均不能直接替代 Shared64 的独立验证。 |
| 停止规则 | 若 Shared64 在独立 development pools 上不能稳定优于单一 GeoShared52，或冻结后在 locked pools 上不能形成精度-复杂度-通信量帕累托优势，则把门控/Shared64 降级为消融，不继续对同一结果集调频点或阈值。 |

### 3.10 双站异构选频与插值伪补全

| 项目 | 内容 |
|---|---|
| 创新思想 | 允许两站分别依据本地功率谱选择不同频点，再通过 IFFT、时间插值、抗镜像滤波和 FFT 把两路稀疏频谱“对齐”，试图利用两站频点并集而不是仅使用交集估计 TDOA。 |
| 理论动机 | 双站独立选频可使每站把有限预算投向本地高信息频点；若非交集频点能够补全，联合频点覆盖可能同时提高有效带宽和跨站相位信息。 |
| 可辨识性边界 | 对频点集合 $\mathcal S_A$、$\mathcal S_B$，互谱 $G_{AB}[k]=X_A[k]X_B^*[k]$ 只有在 $k\in\mathcal S_A\cap\mathcal S_B$ 时由真实双站观测确定。对稀疏频谱 $X_{\rm obs}[k]=M[k]X[k]$ 的确定性线性插值满足 $\widehat X[k]=H[k]M[k]X[k]$，因此 $M[k]=0$ 时不能产生新的独立复频谱观测，且算子秩不超过实际观测数。 |
| 实现方案 | 独立模块 `standalone_frequency_alignment/` 实现严格 Zhai 逐点交换、受控重叠、双站本地选频、Full、Intersection、Zero-Fill、理想周期插值、多相 FIR、周期线性/三次样条、Zhai-Asymmetric 和 Oracle-Union，不接入现有主训练链。 |
| 正式证据 | `运行结果/频谱插值对齐/20260714_184753_411401_synthetic_full` 共 60,000 个基础试验。48,000 个交集可估计试验中，五种伪补全与 `Intersection-Continuous` 的有效性和 TDOA 点估计逐试验完全一致，MAE 增益及 95% CI 均为 `0 [0,0] sample`；缺失频点 NMSE=`0 dB` 表示输出近零，并非恢复成功。 |
| 优点 | 得到了可复核的确定性否定结果，明确区分“频率数组形式对齐”“时延搜索网格加密”和“获得新的跨站复频谱观测”，避免后续在无信息增益的插值器上调参。 |
| 局限 | 正式实验采用理想化单时延/复增益模型、受控随机重叠和连续特征预算；它否定的是无额外先验的确定性伪补全，不是否定联合选频、反馈协调、多快拍低秩恢复或显式参数化预测。 |
| 最终判断 | 路线已按停止规则结束。若重启双站异构采样，必须引入可检验的新信息来源，例如公共核心频点、反馈协调、跨快拍结构先验或联合编码，并重新核算两站传输并集预算。 |

### 3.11 PFRS：剖面有限时延风险约束选频

| 项目 | 内容 |
|---|---|
| 创新思想 | 在消去未知公共源谱和全局复增益后，不再只最大化局部 Fisher 信息，而是在保留局部精度下限的同时，最小化有限时延区间内的剖面广义似然比检验（GLRT）错判风险。PFRS 全称为 Profiled Finite-delay Risk Selection。 |
| 信号模型 | $Y_A[k]=S[k]+N_A[k]$，$Y_B[k]=\rho S[k]e^{-j\omega_k\tau}+N_B[k]$。逐频点未知公共谱 $S[k]$ 与全局复增益 $\rho$ 通过剖面似然消去；设计风险是 nuisance-profiled finite-delay GLRT risk，不是 Bayesian ZZB。 |
| 约束目标 | 在 $\lvert\Omega\rvert=M$、先验区间连续可辨识且 $J_\Omega/J_{\max}\ge\eta$ 的掩码中最小化有限时延风险。$J_\Omega$ 为消去增益后的 Schur 补 Fisher 信息；当前理论网格为 $N=16$、$M=4$、$\eta=0.9$、时延先验宽度 8 samples。 |
| 有限时延确认 | `PFRS_20260716_141935_confirmation` 使用 6 个 selection seeds 冻结掩码、12 个独立 confirmation seeds 验证。PFRS `[-8,-5,6,7]` 的 Fisher ratio=`0.900967`；相对 Zhai-Fisher 的平均风险改善=`0.005813`，95% CI=`[0.005243,0.006355]`，但最坏风险改善 CI 跨零，状态为 `HOLD`。 |
| 连续 TDOA 验证 | `PFRS_CONTINUOUS_20260716_152435_continuous_validation` 表明 PFRS 在阈值区相对 Zhai 的 pooled RMSE 改善=`0.110 sample`，95% CI=`[0.091,0.129]`，大于 1 sample 错峰率改善=`9.75pp`；20 dB 时 MSE/CRLB=`0.9996`。但 PFRS 阈值区和 15/20 dB 合并 RMSE 均弱于 Power，自动状态=`NO_GO`。 |
| 失败机理 | 条件于选中正确主峰后，各方法的局部 MSE 基本贴合 CRLB；无条件 MSE 主要由远端旁峰错选造成。PFRS 把 Zhai 最强模糊峰从约 `0.975` 降至约 `0.868`，但仍保留约 `±1.25 sample` 的强假峰；Power 旁峰低但主瓣宽、局部 Fisher 信息极低。 |
| 固定掩码证书 | `PFRS_FIXED_MASK_20260716_161036_certificate` 穷举全部 $\binom{16}{4}=1820$ 个掩码。1654 个在闭合先验上连续可辨识，$\eta=0.9$ 下仅 8 个可行；PFRS 的最强旁峰=`0.867747@1.237017 sample`，是可行掩码中最低者，且无掩码同时在 Fisher 与旁峰上支配它。正式证书=`FIXED_MASK_SATURATED`。 |
| 优点 | 首次把未知源谱/增益剖面、局部 Fisher 安全约束、有限时延错峰风险和连续旁峰证书放在同一可证伪流程中；清楚揭示固定少量频点下“窄主瓣/高旁峰”与“宽主瓣/低旁峰”的结构冲突。 |
| 局限 | 证书只覆盖冻结的 $N=16,M=4$ 有限掩码空间及确定性源谱、复增益、等噪声和固定先验模型，不是所有压缩编码的普遍不可能性定理，也尚未映射到 urban8 的 CR16 主结果。 |
| 最终判断 | PFRS v1 作为固定掩码主方法未通过连续性能门禁，且同空间调优已饱和；停止 C-PFRS、$\eta$ 重调和 nuisance 扫描。下一候选必须改变编码机制，例如“低频粗定位 + 高频精化”的逐层/可变率有限比特统计编码。 |

### 3.12 PASR-TDOA：剖面后验驱动的主动逐层精化

| 项目 | 内容 |
|---|---|
| 创新思想 | 不再为所有样本固定发送同一四频点掩码。先发送低歧义基础层形成连续多峰 TDOA 后验，再根据当前尚未区分的候选模态，请求每 bit 剖面判别增益最大的下一频点；后验模态置信度和条件方差达标后提前停止。 |
| 与 PFRS 的关系 | 保持 PFRS 的未知公共源谱、未知复增益和剖面似然口径，但把固定掩码设计改成逐样本主动实验设计。PFRS 的固定空间饱和证书不排除该协议，因为 PASR 的频点集合和总传输率随观测变化。 |
| 有限比特协议 | B站复频点采用 subtractive-dither I/Q 量化；每个样本的尺度、频点系数、继续/停止标志和下一频点索引全部计入 bit 账本。主动方法比较4/6/8 bit I/Q，所有静态方法扫描4--10 bit；减性抖动种子和静态时分表假设预共享。 |
| 独立实现 | 新增 `pasr_tdoa/`，包含核心剖面后验/模态/动作/量化、PyCharm正式入口、测试和README；未修改 `main.py`、DAE、V5、PFRS、urban8或现有评估代码。 |
| 强基线与消融 | Exhaustive-Proxy-M2/M3/M4、PFRS、Zhai-Fisher、Power、Uniform、Fixed-Nested、Random-Request、Oracle-Next-Bin、Always4、OraclePower、Fisher-Only、HardTop1及Full16参考。`Exhaustive-Proxy` 是全可辨识掩码枚举后的理论代理胜者，不是经验风险全局最优。 |
| 选择隔离 | 同平均 bit 的静态时分组合、同风险组合和高 SNR 参考只在 development seeds 上选择并冻结，locked set 不参与对手选择。6-bit I/Q 预注册为主检验，4/8-bit 仅作敏感性分析，避免任一位宽通过造成多重选择偏差。 |
| smoke 证据 | `PASR_20260716_192922_smoke` 的无噪声最大误差为 `1.863e-6 sample`，固定分层与同并集后验差为 `2.082e-17`；5568条trial、330条action、3条冻结对手及bit/预算/种子/同源数据/CSV/manifest/3张SVG审计均通过。固定顺序与Always4消融不再收取协议不需要的动作/停止位。状态为 `SMOKE_ONLY`，小样本性能排序不构成结论。 |
| Go/No-Go | 正式locked set的6-bit主检验必须同时通过development冻结的同总bit静态参考、`(seed,trial)`轨迹聚类配对CI、错峰率相对改善至少15%、最高SNR RMSE恶化不超过5%和同风险平均bit降低至少20%。平均bit匹配误差不得超过3%，静态最大bit不得高于PASR。任一关键门禁失败则不接入urban8。 |
| 正式结果 | `PASR_20260716_193437_research` 的6-bit主检验为 `NO_GO`：PASR/同bit静态参考 locked RMSE=`2.04094/2.03700 sample`，成对MSE改善=`-0.0160`，95% CI=`[-0.2275,0.2006]`；gross相对改善仅=`2.15%`，最高SNR RMSE为冻结PFRS的=`2.081`倍。同风险20%节bit、同bit包络、gross、最高SNR和配对CI门禁均未通过；4/8-bit同样失败。 |
| 失败定位 | 量化截幅率为0，4/6/8-bit pooled RMSE均约2.04，说明量化位宽不是瓶颈。Oracle-Next-Bin 6-bit RMSE=`0.52798`，证明4频点主动协议仍有很大理论空间；但PASR动作与Oracle重合率仅约8.7%，当前剖面模态判别增益代理没有正确逼近终端平方误差。10/15/20dB提前停止样本相对Always4明显更差，说明未校准的模态概率/方差不能作为停止证书。 |
| 当前判断 | 冻结PASR v1及其locked集合，不进入urban8，也不在该集合上调置信阈值。若继续，只允许先在全新development集合构造“预期终端风险下降/bit”的动作准则，并用“全局歧义已消除 + 局部精度达标”的双证书决定停止；开发门禁失败则结束主动选频路线。 |

### 3.13 科学完整性审查与实验边界

| 项目 | 结论 |
|---|---|
| 自动门禁 | `experiment_integrity.py` 和 `validate_project_integrity.py` 统一检查实际特征并集、精确 CR、数据/缓存协议、urban8 几何标签、正负 TDOA、GCC/direct 符号、模型输出和 geometry-oracle WLS。 |
| 训练/测试隔离 | PCA 只能在训练/development snapshot pool 拟合；dev 各 SNR 使用同一 fixed trial；locked 使用独立 snapshot pools，且不能覆盖或参与调参。 |
| 缓存边界 | 历史缓存若缺少 seed、snapshot pool、归一化、SNR、定位器、样本数、预算或 baseline 代码指纹，则不得静默复用为新正式结果。 |
| 失败样本 | 主表必须同时报告 valid count/failure rate；跨方法增益使用同一样本的配对 common-valid 统计，防止“丢弃困难样本后 RMSE 变好”。 |
| 通信量定义 | 当前 CR 按连续实数标量数计算：1024 点复信号为 2048 real，CR16 为 128 real/64 complex bins。尚未考虑量化位宽、熵编码和元数据，因此只能称 feature-count fairness，不能直接等同真实 bit-rate fairness。 |

## 4. 创新路线为何从波形重构走向直接统计与 PFRS

1. **纯复现阶段**：先用 DAE-MSE 复现 Chen 论文主链路，发现数据集和定位链路差异会显著影响 Raw/DAE 排序，因此必须先冻结近似复现基线。
2. **Loss-level 改进阶段**：引入 GCC/Peak/NMSE 等任务损失后，TDOA 可明显改善，但时频域经常崩坏，CR 无区分度，说明单靠 loss 权衡不足。
3. **频域 DAE 阶段**：把 Fisher/频带选择思想放入网络结构，仍未解决 waveform decoder 诱导的窄带假信号和宽峰问题。
4. **强基线阶段**：补充 Chen Fig6 与 DFT/CRLB/Cao/Zhai 等强 baseline 后发现，传统任务感知 DFT 已经很强，创新方案必须在相同压缩预算下给出更直接、更可解释的 TDOA 优势。
5. **Direct TDOA 阶段**：转向 compressed-domain likelihood，不再重构 waveform，而是直接由压缩频点互谱相位构造 TDOA posterior。
6. **V5-B 阶段**：单一频点专家在不同 SNR/几何下各有弱点，因此加入非 oracle expert gating。
7. **Top-K 阶段**：低 SNR 主要问题不是 posterior 完全无信息，而是 top1 错峰；top-K 诊断用于判断是否能通过定位几何和多假设搜索恢复这些信息。
8. **异构选频伪补全阶段**：试图利用两站频点并集，但理论恒等式和 60,000 次基础试验证明，确定性插值只重排已有观测，不能补出非交集频点的真实跨站相位；该路线因此停止。
9. **PFRS 阶段**：文献重合审查将宽泛的 NLGSC/CLIGS 收窄为“Fisher 下限约束下的剖面有限时延风险选频”。有限风险和连续 TDOA 均验证了它比纯 Zhai-Fisher 更少错峰，但仍弱于 Power 的全局稳健性。
10. **固定掩码饱和阶段**：全掩码穷举证明当前 PFRS 已是同约束空间的最低旁峰方案，继续调风险权重或 $\eta$ 只会改变问题定义。下一步必须改变固定掩码编码机制，而不是继续局部调参。
11. **PASR-TDOA 阶段**：把固定掩码改为“后验多模态判别—按 bit 请求下一频点—置信停止”的主动协议，并把量化、尺度、动作索引和反馈统一纳入真实 bit 预算。正式locked结果证明协议可运行但v1未超过同bit静态包络；Oracle上界仍很高，失败集中在可实现动作代理与停止证书，而不是4频点预算本身。

## 5. V5 阶段 top-K 的含义和意义

### 5.1 top-K 是什么

对每一个 UAV pair，V5-B 会输出一个关于 TDOA lag 的 posterior 分布。常规做法只取概率最大的一个 lag，即 top1。top-K 则保留概率最高的 K 个候选，例如 top3 或 top5：

```text
pair posterior -> top1/top2/top3 lag candidates -> WLS localization
```

当前 top-K CSV 中每个 pair 包含：

- top1/top2/top3/top5 lag；
- 每个候选的 posterior probability；
- posterior entropy、variance、peak margin；
- pair_weight；
- true_tdoa 和 hit/miss 诊断；
- V5-B expert gating 的 power/geohybrid 权重。

### 5.2 为什么 top-K 有意义

低 SNR 下，posterior 常出现多个峰。若真实 TDOA 在 top3/top5 内，但不在 top1，则说明 estimator 并没有完全丢失信息，只是决策层过早把不确定性压成了单点。此时可尝试：

1. 用 top-K WLS 结合多 pair 几何约束消歧；
2. 用 posterior confidence 剔除低可信 pair；
3. 分析 top-K oracle 上界，判断是否值得继续做 solver-level 改进。

当前低 SNR 结果显示：

| 指标 | 数值 |
|---|---:|
| top1±1 hit | 59.3% |
| top3±1 hit | 71.9% |
| top5±1 hit | 77.4% |
| top5±2 hit | 81.1% |
| oracle expert top1±1 | 65.2% |

这说明继续调 expert gate 的上限有限，但 top-K posterior 仍保留了明显额外信息。独立峰 GeoBeam full 已进一步证明这些候选能转化为真实 TDOA 和定位收益，因此后续不再调整候选或门控参数，而是验证公平性、复杂度与跨场景泛化。

## 6. 当前结论与下一步

### 6.1 当前结论

1. Chen-style paper_repro v3.1 可作为近似复现基线，但不应声称严格复现 Wireless InSite 原论文结果。
2. R20/R20.1、FreqDAE v1-v4 等 waveform decoder 路线已经充分暴露问题，不适合作为当前主创新方向。
3. GeoHybrid/DFT direct 是重要强基线和消融，不再继续调参包装为主创新。
4. 旧 V5-B+ 证明了“压缩域 posterior + 非 oracle Top-K 几何联合决策”能够减少 TDOA 长尾，但其前端为 CR11.64，只能作为机制上界。
5. 严格 CR16 的 V5B-Shared64 已实现并完成首次 full：它保持了对多数压缩基线的优势，但当前融合总体不优于 GeoShared52，说明“两个专家都有效”不等于“门控融合必然有效”。
6. 双站异构选频的确定性插值伪补全没有产生新的互谱信息，已作为否定性机制证据冻结。
7. PFRS 证明了“局部 Fisher 安全”和“全局错峰抑制”需要联合设计，但固定四频点版本在当前有限空间内已饱和且连续验证为 `NO_GO`，不能作为最终主方法。
8. 逐层/可变率候选已具体化为 PASR-TDOA，并完成独立代码和流程 smoke；目前只能称“待正式验证的候选创新”，不能提前写成已成立贡献。

### 6.2 下一步执行标准

| 条件 | 决策 |
|---|---|
| 共享 WLS 对病态几何采用统一自适应重试，所有方法使用相同 failure 语义 | 定位协议通过 |
